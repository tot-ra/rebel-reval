# Storybook equipment inventory

This directory retains fitted weapons, armor, and the original character model inventory note. Runtime bird and mammal GLBs, textures, the forge-cat adapter, and the shared plumage shader now live in [`../animals/`](../animals/README.md); they are colocated with the licensed animal sources and other species models. Equipment scenes continue to use the stable `res://assets/storybook/equipment/` paths.
