# Estonian and Undeutsch forenames in Harju, 1340-1350

## Brief for Character / Dialogue / Narrative

This dossier provides a **usable Estonian male forename pool** for Spring 1343 Reval
characters - labourers, servants, rebels, and hinterland peasants - recorded in German
(Latin/Low German) scripts. The names are drawn from AWB (Akte des Revaler
Stadtbuches), manorial estate records, and scholarly reconstructions of 14th-century
Estonian naming.

**Key decisions:**

1. **Dual name layers.** Estonians in the 1340s carried **Christian saints' names**
   (adopted at baptism under German clerical pressure) and, less commonly, **traditional
   Finnic forenames**. German scribes phonetically transcribed both through MLG orthography,
   producing spelling variants per entry [1][2][3].
2. **No hereditary surnames.** Estonian townsfolk and peasants used **forename only**,
   or **forename + patronymic** (*poeg* / *pockke* = "son of"). Farm or village locators
   (*Muddenkull*, *Koikson*) appear in later records but **not before c. 1380** [3][4].
3. **German spellings are the only written evidence.** The modern Estonian forms below
   are scholarly reconstructions; writers should use the **German-record spelling** in
   Latin/MLG text and the **modern Estonian** only in subtitles or Estonian dialogue
   [1][5].
4. **St. George's Night names.** The 13 April 1343 uprising is narratively tied to
   *Jüri* (George) - the patron saint's day. Use this name for rebel leaders
   deliberately [6].

### Spelling conventions for writers

German scribes recorded Estonian names with **Low German orthographic habits**:

- Vowels: Estonian *ü* rendered as *u* or *w*; *õ* as *o* or *oe*; *ä* as *e* or *ae*
  [1][5]
- Consonants: doubled for emphasis (*tt*, *ck*); *k*/*ck* interchangeable [5]
- Endings: Estonian nominative *-o* / *-e* sometimes preserved, sometimes Germanised to
  *-us* or *-s* [1][5]
- Patronymics: *poeg* ("son") written *pockke*, *poick*, *poge*; always lowercase
  [3][4]

**Example compound forms for character names:**

- *Mattyes pockke* = Mattes son-of (Estonian labourer)
- *Hinrick poick* = Hinrick son-of (young townsman)
- *Jans poick* = Jaan son-of (harbour worker)
- *Marten* = Marten, no surname (forge labourer, servant)
- *Jüri* = Jüri (rebel leader on St George's Night)

### Name layer by social context

| Context | Expected name layer | Confidence |
|---|---|---|
| Estonian labourer / servant in Lower Town | Christian forename only, MLG spelling | attested practice [1][3] |
| Estonian rebel leader (April 1343) | Christian or traditional forename | plausible composite [6][8] |
| Estonian townsman with partial citizenship | Christian forename + patronymic (*poeg*) | plausible composite [3][4] |
| Hinterland peasant (manor farm) | Christian or traditional forename | attested pattern [1][4] |
| Estonian woman (town or rural) | *Liis*, *Mari*, *Anna* - sparse attestation | plausible composite [1][5] |

### Female names (sparse evidence)

Estonian female forenames from the 1340s are **very poorly attested** in surviving
records. The following are usable with caution:

| Modern Estonian | German spelling | Confidence | Notes |
|---|---|---|---|
| **Liis** | *Liis*, *Lise* | plausible composite | Christian (Elizabeth); later well-attested [1][5] |
| **Mari** | *Mari*, *Maria* | plausible composite | Christian (Mary); universal but sparse Estonian 14th-c. record [1][5] |
| **Anna** | *Anna* | plausible composite | Christian (Anna); sparse attestation [1][5] |

**Note:** No Estonian female names are attested in AWB 1340-1350 entries. The above are
projected from 15th-century vakuraamatud and church records.

## Production hooks

- **Character:** Name generator for Estonian labourers, servants, and rebels draws from
  the eighteen-name pool above. German-record spellings for Latin/MLG text; modern
  Estonian for subtitles. Flag *Kalev* as `invented` in any documentary context.
- **Dialogue:** Estonian dialogue lines should use **modern Estonian spelling** for
  readability; German-record spellings only when a German scribe is narrating. Patronymic
  compounds (*Marten pockke*) appear in AWB-style text.
- **Narrative:** St George's Night (13 April 1343) scenes should feature *Jüri* as a
  rebel leader name deliberately echoing the feast day. *Lembit* is appropriate for
  the traditional rebel-king register.
- **Quest:** If a quest requires an Estonian witness name, use **Marten**, **Hinrick**,
  or **Jüri** for highest documentary plausibility. Avoid *Kalev* in any AWB/council
  context.

## Open questions

- **AWB 1340-1343 Estonian name entries:** A dedicated pass through the published AWB
  volumes (Tallinn City Archives) for entries explicitly recording Estonian (Undeutsch)
  personal names would upgrade several `plausible composite` labels to `attested`. This
  overlaps with the R-038 council prosopography gap.
- **Female names before 1500:** The 14th-century Estonian female name pool is an
  acknowledged research gap; the three names above are projections only.
- **Traditional Finnic names in Harju:** Whether names like *Toll*, *Lembit*, *Ain*
  were in active use (vs. legendary/chronicle-only) in 1343 Harju requires specialist
  Finno-Ugric onomastics review.
