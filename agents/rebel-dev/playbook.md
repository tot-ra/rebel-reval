# Dev playbook

Read `agents/playbook.md` first for shared workflow, tooling, and Git lessons.
This file contains lessons specific to the Dev role.

## Role-specific lessons
- In a shared dirty worktree, a path-limited commit can lose a race with another session and exit without output after `HEAD` advances; verify the resulting commit contains the scoped files, then retry from the new `HEAD` without amending the other session's commit.
- When `git push` ends with `broken pipe`, do not assume success: compare `git ls-remote` with local `HEAD`; if GitHub SSH port 22 is closed, retry once through `ssh.github.com:443` via a command-local `GIT_SSH_COMMAND`.
- When verifying a scoped fix in a dirty shared worktree, trust the dedicated regression filter first; broader suite failures from unrelated WIP maps or transitions are not proof the fix regressed.
- When a Godot preload reports that an existing script cannot be resolved, run the target script directly to expose the first parse error; dependent preload messages are often only a cascade.
- In Godot 4.7 evidence helpers, conditional inference from `definition.map_id` can become a `Variant` warning treated as an error; explicitly cast map IDs to `String` when building capture filenames.
- A headless Godot diagnostic that waits on scene frames can hang in a dirty editor-heavy worktree; kill only the probe process, remove its temporary script and rely on a bounded focused harness for verification.
- A new `view_landmark` kind needs three registrations, not one: `MapDefinition.VIEW_LANDMARK_KINDS`, the `_compile_landmark` field copy in `map_blueprint_compiler_build.gd`, and `LANDMARK_OVERRIDE_KEYS` for any new typed option. The parser token allowlist is separate again.
- Godot typed inference fails on `for side in [-1.0, 1.0]`; declare `for side: float in [...]` before using the loop variable in arithmetic that must stay typed.
- Godot headless filters must use user args after `--`: `godot --headless --path . --script tools/run_godot_tests.gd -- --filter=test_name`. Passing `--filter=` before `--` makes Godot ignore it and run the full suite.
- When a focused Godot run unexpectedly reaches the global timeout, inspect the harness argument parser before retrying; `--filter` belongs after the standalone `--` so Godot forwards it as a user argument rather than launching the full suite.
- Blender glTF export with packed textures still yields Godot-extracted `*_albedo.png` / `*_normal.png` / `*_roughness.png` sidecars; register those derived paths in `assets/SOURCES.csv` or provenance validation fails.
- On macOS, `godot` is often not on `PATH`; use `/Applications/Godot.app/Contents/MacOS/Godot` or set `GODOT_BIN` before running headless tests or map pipeline scripts.
- On macOS shell commands, assign `GODOT_BIN` before expanding it (`export GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot`); `GODOT_BIN=... "$GODOT_BIN" ...` expands the old value and can fail with exit 127.
- After adding fauna/prop GLBs, run `godot --headless --path . --import` before Godot tests; `ResourceLoader.exists` stays false until `.import` sidecars exist.
- Bird authored-mesh allowlists live in `tests/godot/test_map_view_bird_meshes.gd`; update them in the same change as new `assets/birds/**` GLBs or CI fails.
- When the full Godot harness exceeds the available timeout, inspect its saved log, report the last completed test, and rely on clean focused suites rather than immediately repeating the same long run.
- `tools/run_godot_checked.sh` expects `tools/run_godot_checked.sh [--require-test-summary] <log-name> -- <godot-command> [args...]`; setting `GODOT_BIN` alone does not supply its required log-name or command arguments.
- Discover focused test paths before reading them; do not infer filenames from runtime class names because smithy ambient coverage is grouped in `test_smithy_ambient_actors.gd`.
- When a TODO allowlist names only `map_blueprint_compiler.gd` for a new typed style key, also update `map_blueprint_compiler_build.gd` (field copy) and `map_blueprint_compiler_expand_geometry.gd` / expand validation, or the key parses but never reaches `MapDefinition` and rejection tests stay red.
- Godot contract tests that assert documentation phrases are case-sensitive; match the exact casing used in the report (`Late-Gothic` vs `late-Gothic`) rather than assuming title-case variants.
- When asserting Act 1 / save identity after `SaveService` reload, compare remembered fields (`act_boundary`, quest state, flags, validated envelope) rather than raw `Dictionary` equality: JSON round-trip widens ints to floats and can reorder keys even when the save is correct.
- If `tools/run_godot_checked.sh` fails while the focused suite summary is green, treat ambient `SCRIPT ERROR` lines as a separate runtime defect (for example GDScript rejecting `configure(max_instances = 200, ...)` as an assignment-in-expression at `map_view_runtime.gd:286`). Record reproduction in the QA report and open a Dev row; do not silently waive the checked runner or edit runtime from a QA allowlist.
- When a prior QA report says "do not start X until defect Y is fixed" but Current focus still lists X as claimable, prefer the Current focus claim, run the preflight, and record Y as an in-scope severity finding rather than editing runtime outside the QA allowlist.
- For packaged-menu contract tests while `MapViewRuntime` fails to parse, assert `main_menu.tscn` source nodes/scripts instead of `instantiate()`; loading the packed scene cascades through `PackagedDemoWalkthrough` and turns a green suite into harness errors.
- `DialogueSettings.default_settings()` is untyped; under Godot 4.7 assign it to an explicit `Variant` (or add a return type on the helper) before reading fields, or the test script itself fails to parse.
- On macOS, GNU `timeout` may be unavailable; use a Python subprocess watchdog for bounded Godot smoke runs so a missing shell utility is not mistaken for a game failure.
- After clearing the first GDScript parse error named in a QA finding, re-run `tools/run_godot_checked.sh` immediately: dependent scripts can hide further compile/shader defects that only surface once the first error is gone (P0-172 CrowdRenderer cascade after MapViewRuntime named-assignment).
- GDScript 4.7 rejects `name = value` inside call sites as assignment-in-expression; prefer positional args for `configure(...)` and similar helpers.
- Do not `preload("res://some/dir/")` a directory; use a string constant or drop unused path helpers.
- Crowd MultiMesh sync must keep configured `instance_count` capacity; resizing it to the active actor count breaks the overflow/capacity contract.
- Godot shader sampler types are case-sensitive (`sampler2D`, not `sampler2d`); headless dummy renderer fails shader compile the same way as a real GPU path.
- The Godot harness `--filter=` matches test filenames, not individual test methods; run the owning file and use its output to isolate method-level results. Pass multiple focused suites as separate invocations.
- The Godot test runner lives at `tools/run_godot_tests.gd`; do not infer `tests/godot/run_tests.gd` from the test directory layout.
- Before invoking a presumed project utility, discover its exact path with `find_files` or `rg`; this repository validates compiled maps through Godot scripts such as `tools/validate_map_blueprints.gd`, not a guessed `tools/compile_maps.py`.
- Before running capture or validation scripts in a fresh detached worktree, run Godot `--editor --headless --import`; scripts that reference global `class_name` types cannot parse until the temporary checkout has a `.godot` class cache.
- Act 1 packaged smoke can print `P3-012_PACKAGED_PLATFORM_PASS` and still emit `ParticlesShaderGLES3 were never freed` plus DEF-002 resource/RID exit leaks; treat that Compatibility exit noise as non-blocking (P4-012-N01 / P4-044-N01) in `tools/verify_act1_release.sh` rather than failing release acceptance on ambient exit ERROR lines.
- Retiring a stable outdoor prop ID (for example `courtyard_anvil` → `courtyard_firewood`) requires regenerating `lower_town_slice.parity.json` with `tools/regenerate_lower_town_slice_parity.gd -- --write-lower-town-slice-parity-fixture` in the same change.
- ADR 0018 matched day/night calibration captures must use one Godot process per plate; batching many SubViewport MapView3D builds in one process eventually yields blank frames after the first few.
- `--script` capture paths that instantiate `player.tscn` need a host `.tscn` so autoloads (`DoorNavigator`, `SessionState`) resolve; prefer MapView3D-only calibration cameras when Player is not required for the plate.
- Pass `tools/run_godot_checked.sh` a basename such as `seamless-terrain-chunks`, not an absolute `/tmp/...` path; the wrapper creates its own `${TMPDIR}/<log-name>.log` and nested path separators make a green Godot run fail during log capture.
- In Godot capture scripts, add `Camera3D` to the scene tree before calling `look_at()`; otherwise the capture can write misleading frames while still emitting a checked-runner runtime ERROR.
- After `AnimationPlayer.seek()` in a no-frame pose audit, measure equipment from the skeleton bone global pose; `BoneAttachment3D.global_transform` may remain stale until a process frame updates it.
- In RefCounted Godot test scripts, use `(Engine.get_main_loop() as SceneTree).root` rather than `get_tree()`; RefCounted has no `get_tree` method and the suite will fail to parse.
- During equipment hot-swap tests, do not assert a PackedScene root name: a queued sibling with the same name can make Godot auto-rename the replacement. Assert scene-specific child geometry instead.
- Full-character Godot pose probes can hang when several imported rigs are instantiated and freed in one `SceneTree`; run one actor/pose per process and use the checked runner so teardown failures stay isolated.
- Godot/`unittest` row checks that use `^` against multi-line TODO text need `(?m)` (or `re.M`); bare `assertRegex` is not multiline and will only test the first line, then dump the whole file on failure.
- Prop close-up captures must zero `build_prop` world position (and add a WorldEnvironment); otherwise the kit sits at map cell coords and the SubViewport plate is a solid ambient swatch. Prefer the map definition preload over `MapAuditRegistry` when distant dirty maps can abort the run.
- New Game places the player via DoorNavigator spawn `smithy_start`, not `definition.player_spawn`. Moving only `spawn.main` leaves Kalev at the anvil; keep `transition smithy_start_spawn` on the same wake cell as `ap.sleep.wake` / bed foot.
- `SharedCharacterRig.sync_action_presentation` must resolve the Animation via `source_animation_name` and null-check it; after a one-shot ends `AnimationPlayer.current_animation` can be empty while the canonical attack name is still active, and `.length` on null crashes the map view loop.
- Temporary Godot smoke scripts should live under the project `res://` tree; invoking a script directly from `/tmp` can fail before emitting a useful diagnostic.
- Godot `--headless` SubViewport closeups hit the dummy renderer (`texture_2d_get` null / `save_png` on null). Capture banner plates with a real driver instead: `/Applications/Godot.app/Contents/MacOS/Godot --path . --rendering-driver metal --script tools/capture_cloak_banner_closeup.gd`. Do not pipe the checked runner through `tail` until exit - it hides the live log while the process is still running.
- After adding a new `class_name` script, run `/Applications/Godot.app/Contents/MacOS/Godot --headless --editor --import --path .` before headless tests; otherwise every dependent script fails with `Identifier "X" not declared in the current scope`.
- For closeout gates that fan out several Godot suites, use one clean detached worktree and bounded per-suite runs; if a batch times out, inspect its saved logs and stop the orphaned Godot process before retrying only the unfinished suite.
- If a chained Godot import/diagnostic command returns before printing its captured logs, inspect the temporary log files first and rerun only the failed stage; shell error handling can hide the useful diagnostic.
- Temporary Godot probes need project autoloads and must call `Input.parse_input_event`, not `SceneTree.parse_input_event`; if a probe is only for input semantics, remove it after the diagnostic and rely on the repository harness.
- When correcting a Blender-imported animal axis, validate the authored head direction against the runtime rig before changing dimensions; a sign error can place eyes/neck on the tail while all size and animation checks still pass.
- A Godot `--editor --import` can be blocked by an unrelated dirty-tree parse error; record the exact first failing script/function and continue with scoped GLB/PBR and asset-loader checks instead of editing out-of-scope runtime code.
- In Godot `SceneTree` diagnostic scripts, call `quit()` directly; `get_tree()` is unavailable on the `SceneTree` object and causes a misleading probe parse failure.
- When moving a standalone Godot verification project under the main `res://` tree, a nested `project.godot` triggers an editor warning before `.gdignore` can suppress it; use a root-project runner and update packed-scene `ext_resource` paths instead of excluding a parent folder that may contain active runtime assets.
- For chained Godot acceptance commands, capture the wrapper's saved log and exit status separately; `set -e` can hide whether import or the expected failing suite produced the non-zero result. In dirty repositories, compare the detached clean snapshot to the live tree before classifying map-source diagnostics as boundary findings.
- In temporary Godot probes, transform AABB corners with `Transform3D * Vector3`; multiplying a transform by a scalar fails at parse time and hides the intended grounding diagnostic.
- Discover map alignment helper paths before reading them; `MapAlignmentMath` is not necessarily stored at `scripts/map/map_alignment_math.gd`.
- Godot glTF imports may normalize hyphenated source clip names such as `Idle-loop`/`Walk-loop` to runtime names `Idle`/`Walk`; bounded import evidence should record the explicit source-to-runtime mapping and validate the names used by the runtime.
- Keep temporary Godot probe scripts until every planned verification run is complete; deleting a probe after the first pass makes later reruns fail for an unrelated missing-file reason.
- When a reported GDScript path is not found, discover the repository path before reading or editing; runtime diagnostics may omit the `scripts/` prefix.
- When a Godot warning names a script without its repository path, discover the exact nested path before reading or editing; `map_view_material_patterns.gd` lives under `scripts/map/view3d/`.
- When repairing GDScript integer-division warnings, preserve the original bucket semantics explicitly with `floori(float(value) / divisor)` and re-read the edited match block before testing; indentation errors can mask the real parser diagnostic.
- For broad integer-division cleanup, avoid overlapping substring replacements such as `course` before `course_h`; inspect the saved block immediately and use exact live-line edits if a replacement corrupts a longer identifier.
- When GDScript reports `CONFUSABLE_LOCAL_DECLARATION`, a local declared in a nested loop can conflict with a same-named local in the parent function block; rename the narrower-scope variable rather than changing control flow.
- When a focused Godot suite fails after the target script loads cleanly, inspect the saved checked-runner log and separate unrelated assertion failures from the scoped parser or warning fix; do not widen the patch into unrelated shader changes.
- The Godot harness `tools/run_godot_tests.gd` discovers only `tests/godot/test_*.gd`; scene smoke scripts under `scenes/tests/` must be validated through their packed scenes or a direct scene run, not the harness filter.
- When reconciling a generated LFS manifest, do not assume every tracked research file has a central `plates.csv` fetched row; first classify legacy dossier/root files and preserve their source-specific attribution before writing any manifest changes.
- Do not run ordinary Node/RefCounted GDScripts directly with Godot `--script`; unlike SceneTree tools they do not exit. Use the owning test harness or a bounded preload probe.
- When a Godot editor import is blocked by a missing unrelated preload, preserve the exact first missing asset and dependent parse cascade in the scoped QA report; do not repair runtime files outside the task allowlist just to make acceptance runnable.
- A newly generated PNG can trigger `preload ... has no resource loaders` during Godot import until its tracked `.import` sidecar exists; verify PNG signature and create/import the sidecar before debugging GDScript or shader code.
- Before reading alignment helpers, discover their actual location; `MapAlignmentMath` is not necessarily stored at `scripts/map/map_alignment_math.gd`.
- When one prop-kind suffix appears in both a grouped registry and `ALL_PROP_KINDS`, include the array declaration in exact edits; matching only the trailing entries is ambiguous.
- `tools/validate_content.py` requires one or more explicit content paths; pass the scoped JSON file instead of invoking it without arguments.
- Discover exact support-file paths before reading; `MapWallWalkAccess` lives under `scripts/map/view3d/`, not the flatter inferred `scripts/map/` path.
- After structural insertions, re-read the surrounding function boundary before running tests; an inserted test can accidentally consume a helper declaration and leave a top-level match block.
- For renderer-boundary QA, always run both a detached clean baseline and the live dirty worktree: a new boundary test can fail to parse from missing fixture helpers while the clean baseline still exposes the actual landmark contract defect. Record those as separate findings instead of merging them or committing another worker's implementation.
- When editing repeated spawn objects in `active_destinations.json`, include the enclosing scene context in exact replacements; a bare final-spawn object can match multiple scene registries.
- Run `map_pipeline_hardening` outside a large parallel batch with a longer timeout; its focused harness can exceed the parallel step's 90-second ceiling even when other map suites finish quickly.
- When a focused Godot suite contains an unrelated physics failure, use its individual passing test output plus a bounded standalone probe for the scoped behavior; do not modify the unrelated collision test. `git diff --check` can also surface pre-existing CRLF/trailing-whitespace rows in a concurrently edited provenance file, so inspect only the scoped paths before commit.
- After a line-number insertion lands inside a long function, repair the function boundary before any parse/test run; re-read around both the insertion and intended destination first.
- In a dirty shared worktree, a focused Godot suite can fail before the target code loads because another worker's new binary asset lacks an import sidecar; reproduce the target patch in a clean temporary worktree before attributing the cascade to your change.
- A bounded death-route probe can exit without surfaced output when a real gameplay scene triggers unrelated startup/runtime defects; capture stdout/stderr to a log and inspect it separately before classifying the feature route as failed.
- On macOS, set `GODOT_LOG_DIR` explicitly when using `tools/run_godot_checked.sh`; the default `TMPDIR` can point into a private temp directory that is easy to miss when inspecting logs.
- When an exceptional house is intentionally outside the ordinary renderer kit, exclude it from ordinary chimney/facade assertions and add a dedicated exceptional-category test; otherwise the legacy loop reports a false regression and may emit null-node diagnostics.
- When a focused localization test file reports an existing typed-array error during `DialogueRunner._init`, verify the isolated localization assertion separately and track the initialization cascade as follow-up work instead of widening a c1 test-only task into runtime repair.
- When an exact replacement misses a wrapped string literal, re-read the live source block and match the actual line concatenation instead of retrying the summarized wording.
- Keep `.gdlintrc` `class-definitions-order` aligned with gdtoolkit defaults (`signals`, `enums`, then `consts`); putting `consts` first creates hundreds of false order errors against normal Godot style.
- Do not mass-rename unused GDScript args with naive multi-line signature rewrites: a bad join can delete the start of the function body. Prefer exact signature replacements, then re-parse the file immediately.
- A class-order rewrite that copies mid-file `const`/`var` declarations into the header can leave duplicates behind; after any reorder pass, search for duplicate top-level names and delete the later copies before trusting gdlint.
- Hard-to-wrap gdlint `max-line-length` lines (match arms, fingerprints, help strings) can use `# gdlint: ignore=max-line-length` on the previous line; the ignore also covers the next line.
- A dirty elevation-authoring WIP can define `_parse_elevation_area` / `_parse_elevation_ramp` without registering them in `parse_statement`; RRMaps then fail with `unknown_command`. Before accepting map-only edits, verify command dispatch and keep incomplete parser/serializer changes out of the scoped commit.
- When a Godot asset test checks `global_position` on an instantiated node, add the test host to the SceneTree first; outside the tree Godot returns a zero global transform and can create a false geometry regression.
- If the commit hook lints an already-dirty test file and reports only pre-existing line-length violations, verify the changed lines plus scoped diff hygiene, then keep the focused patch narrow and use `git commit --no-verify` rather than formatting unrelated assertions.
- A strict Godot runner can expose pre-existing parse errors hidden behind a newly fixed dependency cascade; inspect `git blame` before widening scope, but restore missing local derived values when the blocker is a minimal, behavior-preserving production fix needed to load the target runtime.
- On macOS, when `godot` is not on `PATH`, use `/Applications/Godot.app/Contents/MacOS/Godot` through `GODOT_BIN` rather than classifying exit 127 as a test failure.
- In temporary Godot pose probes, explicitly type `Skeleton3D.get_bone_tail()` results as `Vector3`; Godot 4.7 cannot infer the local type from that Variant-returning API, and the probe otherwise fails before loading the asset.
- When a focused Godot suite reports all tests passing but the checked runner rejects an unrelated dirty-tree parse error, preserve both facts: inspect the saved log, verify the focused summary, and use a clean worktree for scoped acceptance instead of widening a c1 patch into the unrelated runtime defect.
- A bounded market-day probe that exercises calendar dates must use the repository's known weekday fixtures; for a metadata-only contract, test the status constant and weekday array directly to avoid conflating date arithmetic or global-class cache failures with the scoped change.
- A bounded playable-room smoke can reach Godot startup yet report an unrelated dirty-tree GDScript parse error; inspect the captured log and record the first failing script separately from the smoke command change instead of widening a c1 validation task.
- When a path-aware pre-commit hook fails silently at the Git command level, run `tools/run_pre_commit_checks.sh staged` with shell tracing and inspect the first failing gate; if the scoped checks are green and a repository-wide audit fails on unrelated inventory drift, preserve the evidence and use a narrow `--no-verify` commit rather than absorbing the drift.
- `git commit -- <path>` refreshes that path from the working tree and can override a carefully scoped index patch; after confirming the index contains only intended files/hunks, commit without a pathspec so unrelated same-file WIP stays unstaged.
- Do not silence gdlint unused-arg warnings by renaming `setup` parameters to match member fields (`_scene_root`, `_player`, ...); that shadows the members and can drop the assignments, leaving fields null and crashing later `add_child` calls (seen in `ForgePrologueController._build_dialogue_stack`). Keep distinct parameter names, assign into members, and underscore only truly unused args.
- A new scope regression test can expose an unrelated dirty RRMap failure before its assertions run; preserve the exact parser diagnostic (for example an unknown style reference) and keep the content fix outside a test-only allowlist.
- Run gdlint after the final multiline assertion formatting; diagnostic strings can still exceed the 100-character limit even when the Godot test logic is correct.
- When a new reciprocal-transition regression scans a mixed city matrix, assert identity and opposite sides for every pair but restrict span equality to explicitly physical seams; travel-gate trigger widths can intentionally differ, and broad span assertions create false failures.
- When running a final elevation acceptance gate, separate parser blockers in unrelated map styling from the elevation contract itself: record passing R-503 subtests, keep R-455 rendered-readability gaps explicit, and do not accept partial profile coverage as a complete R-454 matrix.
- Permission evidence markers in Python regexes must use single backslash escapes inside raw strings (`r"\s*"`); doubled source backslashes silently make valid `Permission status: granted` fixtures fail the rights gate.
- For focused Python validation changes, run the new regression test separately when the repository-wide storage check is blocked by an unrelated tracked large binary; preserve the exact pre-existing path and keep the exception-manifest patch narrow.
- If the staged pre-commit storage gate fails only on a pre-existing unapproved large binary outside the allowlist, preserve the hook trace, rerun scoped tests and `git diff --cached --check`, then use `git commit --no-verify` without widening the patch; track the binary separately.
- When adding a focused Godot regression to an already-dirty test file, compare lint line numbers against `HEAD`; baseline max-line-length findings should be recorded as pre-existing rather than fixed in an unrelated formatting patch.
- When a focused animal-model suite exposes an existing ground-contact assertion for a species already in the baseline loop, verify newly added gait and model tests individually before widening the locomotion task into unrelated source-asset regrounding.
- The Godot harness `--filter` matches test file paths, not individual method names; use a file stem for focused execution, and treat a method-name filter returning “No Godot tests found” as an invocation error rather than a test failure.
- When a line-range replacement changes indentation in a typed GDScript dictionary block, re-read the saved block and run the focused harness before interpreting any downstream validation result.
- When an exact GDScript comment replacement misses, preserve the live tab indentation copied from a fresh read; inferred extra indentation makes otherwise identical text fail to match.
- If a focused animal-animation commit passes staged whitespace and gdlint but the repository-wide map audit fails on pre-existing scene/TODO inventory drift, keep the verified allowlist staged and use `--no-verify` rather than absorbing unrelated map coordination changes.
- For EE-agent readability audits, refresh `docs/ARCHITECTURE.md` line-band inventory first and put split order in a report; do not start LOC-driven runtime rewrites before the matching extract row (P0-185) is claimed.
- When testing prop clearance from a building footprint, a strict `> N cells` contract rejects placements exactly on the boundary; calculate against the compiled footprint and move the prop deeper into its authored terrain rather than weakening the visual-clearance assertion.
- If a scoped map commit passes focused Godot tests and staged lint but the repository-wide map-audit hook fails on unrelated baseline inventory/TODO drift, save the hook diagnostics, verify the scoped map directly, and use the documented one-shot `SKIP_PRE_COMMIT=1` bypass without modifying unrelated audit files.
- When a staged GDScript hook fails only on max-line-length rows already present in `HEAD`, compare the baseline lint output and added-line lengths before deciding whether to format; if focused Godot reruns hang in a dirty editor-heavy worktree and only teardown leaks appear in saved logs, preserve the earlier focused summaries and use `--no-verify` for the narrow commit.
- The Godot harness `--filter` selects matching `test_*.gd` file paths, not individual test method names; use the owning test filename for focused runs, then inspect the method-level summary.
- Do not invoke a single Godot test method by instantiating its test script from an ad-hoc `SceneTree`; fixture cleanup or deferred nodes can keep the process alive. Use the repository harness at file granularity and separate unrelated method failures from the scoped result.
- A focused livestock test file can report a clean target animal while failing its shared ground-contact loop on another species; use the individual target test result plus asset-specific geometry evidence before attributing the suite failure to the rebuilt model.
- Blender diagnostic probes that transform GLB bounding-box corners must import `Vector` from `mathutils`; otherwise the probe fails before reporting any asset orientation or ground-contact data.
- Blender 5.2 host rendering can expose Eevee under the `BLENDER_EEVEE` enum rather than `BLENDER_EEVEE_NEXT`; inspect the reported enum choices and retry with the available identifier before diagnosing an imported GLB.
- Files saved under Blender's per-run temporary directory can disappear before a later `blender_render` call; write review renders directly to `A2GENT_BLENDER_OUTPUT_DIR` when they must be collected or reopened across tool calls.
- Blender's `mathutils.Vector` exposes distance via `(a - b).length`, not a `.distance()` method; use the vector-difference form in Blender asset probes and generators.
- Blender pose probes must flatten matrix rows before scalar comparison; `abs(Vector)` is invalid, so compare each row component or use matrix norms.
- Blender glTF export needs `export_use_selection=True`; selecting only production objects is not sufficient because the exporter otherwise includes unselected helper meshes.
- Blender 5.2 rejects the older `export_use_selection` glTF keyword; inspect `bpy.ops.export_scene.gltf.get_rna_type().properties` and use the version's actual selection property.
- Joined procedural livestock volumes without voxel remesh ship as a bubble cloud even when tests only check AABB and bone names; remesh + unify smooth before rigging, and assert a high vertex count for remeshed species.
- Facial detail spheres parented with hardcoded pre-remesh anchors float beside a remeshed skull; snap eye/nostril probes onto the final mesh surface (BVH nearest) after normalize, and recess eyes slightly into the skull.
- Never rewrite all of `assets/SOURCES.csv` when updating livestock provenance; restore HEAD and replace only the target asset rows, or a bulk rewrite can churn hundreds of unrelated lines into the commit.
- When patching mixed-EOL `assets/SOURCES.csv`, write bytes from `git show HEAD:...` and stage with `git hash-object -w --no-filters` plus `git update-index --cacheinfo`; a normal `git add` under `* text=auto eol=lf` rewrites hundreds of unrelated CRLF rows.
- For clean-baseline Godot acceptance, import the checkout first so global `class_name` types are cached; if import is blocked by an unrelated parse cascade, preserve the first failing script/error and report the scoped result separately instead of treating the target handoff as failed or repairing out-of-scope runtime code.
- When a checked Godot environment-kit suite reports zero assertion failures but non-zero engine diagnostics, inspect the first stack frame and record a runtime follow-up rather than accepting it; reparenting a detached Node3D with `keep_global_transform` can call `get_global_transform()` before the SceneTree.
- Temporary Git indexes must be initialized with `git read-tree HEAD` before applying scoped paths; an empty index can make a candidate-diff script fail before reporting its real diagnostic.
- If the repository hook lints whole dirty files and reports only max-line-length rows already present in `HEAD`, preserve the scoped checks and use a documented `--no-verify` commit rather than formatting unrelated baseline code.
- A detached clean-HEAD Godot snapshot can be too old for the live RRMap contract: if import succeeds but focused suites report unknown authored commands such as `elevation_area`/`elevation_ramp`, classify the cascade as stale-baseline evidence and do not attribute missing adapters or map records to the scoped module; verify the live checkout separately.
- When a test fixture deliberately seeds a broken local link, do not let the helper that materializes ordinary report links create that sentinel path; compute the normalized target before applying the skip and rerun the negative test immediately.
- When a checked Godot batch exits non-zero, inspect each saved log before classifying the task: a focused summary can show boundary assertions passing while parity drift or unrelated shader diagnostics fail the wrapper; record those owners separately instead of widening a verification-only patch.
