# Dev playbook

Read `agents/playbook.md` first for shared workflow, tooling, and Git lessons.
This file contains lessons specific to the Dev role.

## Role-specific lessons

### Godot 4.7 contracts
- Godot 4.7 rejects `name = value` inside call sites as assignment-in-expression. Use positional args.
- Typed inference fails on `for side in [-1.0, 1.0]`. Declare `for side: float in [...]`. Values from `Dictionary.get()`, untyped arrays, `pop_front()`, `load()`, `load().new()`, `Node.get_class()`, and `Image.get_width()` / `get_height()` / `get_pixel()` often need an explicit `Variant` / typed local under warnings-as-errors.
- `DialogueSettings.default_settings()` is untyped. Assign it to an explicit `Variant` before reading fields.
- Shader sampler types are case-sensitive (`sampler2D`, not `sampler2d`).
- `Dictionary.merged()` is not a constant expression. Shard merges need a lazy static cache, not `const PROFILES = base.merged(shard)`.
- Do not `preload("res://some/dir/")` a directory. Do not call `has_method()` on preloaded Script classes in contract tests.
- A brand-new `class_name` is invisible to already-loaded scripts on the first `--import`. In bootstrap/runtime hooks, `preload` the script, type the instance as `Node3D`, and `call("bind", ...)`. Do not write `as NewClassName` until a later Godot run has registered the class.
- `Camera3D.look_at` requires the node to be in the tree. Add the camera first, then `look_at`. A 1440x810 capture near 20 KiB usually means the camera never aimed at the stage.
- Isolated capture scripts must not `preload` `combat_room.tscn`. That scene pulls `SessionState` and can fail the render wrapper's first compile; instantiate `CombatRoomEnemy` / the target archetype instead.
- In RefCounted test scripts, use `(Engine.get_main_loop() as SceneTree).root`, not `get_tree()`.
- `%` treats an Array RHS as the placeholder argument list. Format one `%s` with `str(value)`.
- `CONFUSABLE_LOCAL_DECLARATION`: rename the narrower-scope variable. A navigation probe can also fail when a loop iterator is redeclared in the same scope.
- Keep `.gdlintrc` `class-definitions-order` aligned with gdtoolkit defaults (`signals`, `enums`, then `consts`).
- Hard-to-wrap `max-line-length` lines can use `# gdlint: ignore=max-line-length` on the previous line. Do not insert a one-method regression into a large legacy `test_*.gd` that already exceeds the cap; put it in its own file.
- Inline rrmap fixtures in `test_*.gd` must keep every source line at or under 100 characters. Put `seed=` on the `map` line and drop default `scope`/`palette`/`active` flags. Do not move those options onto the next line: the parser reads that as a new statement and the fixture fails only at runtime.
- On-commit gdlint includes staged `tests/**/*.gd`. Do not inline `CAST_EXECUTOR.execute(MagicResolver.cast(...), ...)` on one line; extract a `_cast_on` helper first.
- Do not silence unused-arg warnings by renaming `setup` parameters to match member fields. That shadows members and can leave them null.
- `Color(255, 243, 222)` is a float colour 255x too bright. Use `Color8(...)` for 0..255 values. When a plate goes flat white only at some sun angles, print the shader uniforms before blaming the shader under test, and render the HEAD shader at the same state as an A/B baseline.
- Swapping a `StandardMaterial3D` with `vertex_color_is_srgb` for a `ShaderMaterial`: spatial `COLOR` is raw, so decode sRGB in the shader behind a uniform (see `map_view_flag_cloth.gdshader`). Do not convert the mesh colours instead; tests such as `_assert_red_field_white_cross` read the stored sRGB values.
- Morning ground mist `fog_light_color` must follow `day_blend`. A constant pale `FOG_MORNING_COLOR` paints the harbour as a light-grey sheet from `FOG_HOURS_BEFORE_SUNRISE` through first light. Keep rain-only haze on the old pale-to-rain lerp when mist is absent.
- Godot exponential height fog at y=0 is `1-exp(-(fog_height-y)*height_density)`. `FOG_MAX_HEIGHT_DENSITY` 1.1 at height 3.5 is ~0.98 cover and hides boats; keep peak waterline cover in 0.25-0.55. Reuse `tools/capture_ws02_glint.gd` for harbour fog plates, then copy to the task's `fog_dawn_*` names so leftover `ws02_*` files stay with WS-02.
- A custom spatial `light()` receives fragment-to-light varyings. `LIGHT_COLOR` already includes PI: Lambert is `NdL * ATTENUATION * LIGHT_COLOR / PI`, and ALBEDO is multiplied after `light()`. `SPECULAR` then only scales ambient/probe specular, so gate branches (for example seen-from-below) through varyings.
- The gameplay camera is orthographic and its mirror direction points north-west at 30 deg. Sun or moon glints appear only when the body is low in the north-west (evening; a moon about 8 deg up), never at noon. Scan `SkyAstronomy` directions against the camera before choosing capture times.
- Water `cloud_darken` is a pale overcast veil (`mix` toward `horizon * (0.83, 0.87, 0.93)`), not a luminance multiply. An isolated `--set=cloud_darken:0` off pair can be darker than the on plate while weather-overcast still reads much darker than clear noon. Do not retune the veil to force "on darker than off".
- Enclosed still-water contours (`TERRAIN_WATER` ponds, ditches, moats) must clip the radius-4 Gaussian to the authored water mask. Otherwise a short dirt causeway and its travel opening fill in (R-529 monastery east ditch). River and sea keep the broad field so stair-stepped banks can still round.

### HUD and magic input
- Persistent HUD strips must not share a screen band. Quick Access is bottom-right and 780px wide; its help labels composite through a center overlay and look like a broken font. Keep the spell bar bottom-left and list granted recipes, not the full element catalog.
- `set_input_as_handled()` does not stop sibling `_input` handlers. Do not bind `spellforge_cast` to LMB: `MapClickInputController` already owns left click for attack / interact / travel. Number keys cast learned slots; the cookbook uses Enter and on-screen buttons.
- The 3D map hides the 2D logic root, so `MagicProjectile2D._draw` is invisible in play. Mirror deliveries in `MapViewMagicVfx` (orb, pulse ring, knockback cone) without naming a spell.
- `as ClassName` on a Node stored in meta/array errors after `queue_free` ("Trying to cast a freed object"). Call `is_instance_valid` on the Variant first, then cast. Validity after the cast is too late.

### Harness, import, and capture
- On-commit Godot resolution should honor `GODOT_BIN`, then `godot` on PATH, then `/Applications/Godot.app/Contents/MacOS/Godot`.
- `tools/run_godot_tests.gd --filter=` takes exact comma-separated file stems. `--reverse` after the user `--` runs the same set newest-name-first so SessionState leaks can be proven in both orders.
- Do not add a public `const` / preload name on `tests/godot/test_case.gd` that a child `test_*.gd` already declares (`BindingSettings` is one). Godot then fails to parse the child. Load helpers inside the method, or pick a unique name.
- After `add_child` on an in-tree parent, the child is often already ready. `await node.ready` then waits forever for a second enter-tree. Use `until_ready(node)` on `test_case.gd`.
- `TestCase.skip(reason)` plus an immediate `return` quarantines a method the awaiting harness newly fails. The harness prints SKIP and does not count it. Unskip in the follow-up row, do not delete the body.
- Do not `await` a helper coroutine (`_settle_frames`, and similar) from a `test_*` method. Inline `await tree.process_frame` in the method body. A nested FunctionState can make the harness treat the outer test as finished, so the next method starts and can `free()` fixtures the first method still uses.
- Combat/quest files share SessionState, ContentDB, InputMap, and root hosts. `is_loaded()` is not enough before reuse: a prior file can leave a narrower loaded corpus. Restore through `restore_demo_session()` / harness `isolate_session_globals()`, and `free()` leftover hosts (the harness does not pump `queue_free`).
- `after_each()` overrides must call `super.after_each()` or `restore_demo_session()`. Skipping it drops the TestCase demo restore. After `SessionState.content_db.load_from_directories` of a non-demo corpus, call `restore_demo_session(true)`: isolation sentinels can still pass `demo_content_ready()`.
- Settings overlay tests that apply live `UserSettings` must reload gameplay accessibility and reset guard toggle in `after_each`. Reloading only audio/dialogue leaves toggle-guard on later combat files.
- Do not run two Godot harness processes against the same worktree at once. Parallel runs contaminate InputMap and look like order-dependent combat failures.
- `SkyWeather3D.advance()` calls `_update_rain`, which reads `global_transform`. A `MapView3D` created in a test and not added to the tree will ERROR four times and fail the harness. Use `set_weather()` plus `apply_cycle_progress()` when you only need the named preset, or `add_child(view)` before `advance()`.
- `SkyWeather3D.snapshot_state(progress, days)` must write those arguments onto the local heading clock (`_cycle_progress`, `_elapsed_days`). Restore-and-advance tests otherwise compare a live sky that is still on the default noon clock against a restored sky that used the snapshot payload. Settled-regime heading assertions must include the live `wind_gust()`.
- Skip `godot_render.sh` while another render is already using the GPU. An idle Godot `--editor` does not always lock the wrapper (it uses a shadow `--path`); still capture one probe plate first and reject empty or black output. A 1280x720 evidence plate near 20 KiB is empty. After a `ws02`/`ws07` capture, copy to the task prefix and restore the overwritten originals.
- After adding a `class_name`, new GLB, or new runtime audio file, run a headless import before tests. `ResourceLoader.exists` stays false until `.import` sidecars exist. Do not invent a placeholder `path=` / `dest_files=` hash in a new sidecar: Godot tries to load that dest on the first `--import`, and `preload()` of the audio then fails the whole script graph. Let import rewrite the sidecar, then commit that file.
- Tests for fade-gated SFX (emerge after a low-pass opens) must hold the muffled state until the mix actually reaches 1. A one-frame dip leaves `lowpass_mix` near 0, so the unfiltered cue fires on the next AIR frame; that is correct runtime behaviour, not a cancelled pending cue.
- `verify_clean_checkout_load.sh` must reject a missing `GODOT_BIN` before `git worktree add`.
- Headless SubViewport captures hit the dummy renderer. Take PNG evidence through `tools/godot_render.sh` (add `--rendering-method mobile --rendering-driver metal` for Metal plates) and never with the bare Godot binary, which pops up a window. The minimized wrapper window can still produce viewport images, but the main loop may skip drawing while it is minimized: `RenderingServer.get_rendering_info` and frame deltas then repeat identical values for every camera. For GPU timing, render into a fixed-size `SubViewport` and time `RenderingServer.force_draw()` plus a render-target readback (see `tools/capture_vegetation_benchmark.gd`). Do not pipe the checked runner through `tail` while it is still running.
- The headless dummy renderer drops MultiMesh instance data: `get_instance_transform()` returns identity and `get_aabb()` is empty, while `instance_count` survives. Any census that needs per-instance positions or frustum culling must run through `tools/godot_render.sh`.
- `MapView3D.create()` only stages assembly. A capture that renders right after `add_child` shows sky and bare ground on large maps; `await view.assemble_async()` first, then `update_active_chunks_from_logic_positions([definition.player_spawn])`. Identical luma numbers across different maps mean nothing was built.
- Judge exposure with numbers, not one plate: `tools/capture_brightness_tour.gd` prints mean/p50/p90 luma for the gameplay camera at five times of day. Under AgX a daylight street needs roughly 90-110 mean luma; the old 1.2 sun gave ~50. A low sun puts most streets in shade from the dimetric camera, so check 17:00, not only noon.
- A follow-up that reuses a capture tool still writes that tool's `wsNN_*` filenames. Copy the new plates to the follow-up names first, then `git restore --source=HEAD` the tracked originals. Leaving the predecessor path dirty folds new evidence into the wrong task.
- Headless DisplayServer has no pasteboard. `clipboard_get` emits ERROR and fails the harness. Guard `clipboard_set` with `DisplayServer.has_feature(FEATURE_CLIPBOARD)` and assert the composed text, not the OS clipboard.
- ADR 0018 day/night plates need one Godot process per plate. Add `Camera3D` to the tree before `look_at()`.
- Temporary Godot probes must live under `res://`, call `quit()` on SceneTree (not `get_tree()`), and use `Input.parse_input_event`. Keep them until every planned rerun is done.
- Godot 4.7 headless dummy renderer does not round-trip `MultiMesh.get_instance_transform()` after `set_instance_transform()`. Assert authored transforms before commit.
- MapView3D `_process` pushes the weather uniforms to the water materials every frame. A capture that overrides material uniforms (wind, foam, debug colours) must call `view.set_process(false)` after warm-up, or the overrides are silently overwritten. `viewport_get_measured_render_time_gpu` returns 0 for SubViewports on this Mac. To compare shader cost, measure wall-clock frame time with vsync off at 2560x1440.
- The headless suite compiles shaders on the dummy renderer, so a `[test] … shader_set_code` diagnostic is a real shader error. Godot rejects a `sampler2DArray` function parameter that is fed textures with different filter or repeat hints, so give every texture passed to one helper the same hint.
- Never pass a `hint_screen_texture` (or depth) sampler into a shader function: Godot 4.7 binds a default texture there and the read comes back near-black. Sample in `fragment()` and pass colours or UVs.
- Godot 4.7 Compatibility uses reverse Z too: near plane is NDC z = +1, empty depth reads 0. Only the raw-to-NDC map differs (`raw * 2 - 1` on Compatibility, `raw` on Forward/Mobile). Do not test for sky with `raw >= 1`. Decode through one `#if CURRENT_RENDERER == RENDERER_COMPATIBILITY` helper (see `_view_position` in the water shader); a hard-coded Compatibility map silently skews every Metal capture plate.
- `FRONT_FACING` is unreliable on view water: some map-edge strips are wound the other way. Test the camera height against the surface instead.
- `hint_screen_texture` is copied before the transparent pass, so a screen pass never sees the water surface. `Engine.time_scale = 0` does not stop shader `TIME`; for before/after plates pin it with `ProjectSettings.set_setting("rendering/limits/time/time_rollover_secs", 0.000001)`. Moving boats still differ between runs, so compare against a second run of the same build.
- Hide `FogOfWar` in perspective lens captures: it blurs by distance from the absent player and smears Metal plates through mip levels.
- View water sits only `WATER_SURFACE_LIFT` (0.006 units) above the gameplay bed recessed by 0.08. Any vertex displacement that pushes water down exposes the bed on rivers, ponds and shore vertices. Budget wave geometry against that column, not against physical wave heights. Open-sea cells render a deeper basin (`field["bed_positions"]`, WS-13b) that only the ground mesh uses; `field["positions"]`, `ground_height` and everything else keep the flat bed.
- Deepening rendered geometry under a depth-reading shader changes its look. Keep the old column by clamping the scene depth to where the eye ray meets the old plane, re-encoded through the same raw-depth round trip as a depth sample (`_flat_bed_view_depth`), and flag the meshes that own that plane (UV2), not shared materials. Anything placed metres below the surface also survives the near-plane clip of the whole-map overview camera, so keep extra floors off land borders and map corners.
- Children of the view `Terrain` root named `Terrain_*` are treated as water surface meshes by tests (`test_r455_city_elevation_readability`). Name new terrain-level nodes without that prefix, and rerun the focused suites after any node is added or moved, not only before.
- When a Godot preload cannot resolve an existing script, run that script directly to expose the first parse error. After clearing it, rerun immediately: dependent compile and shader defects only surface once the first error is gone.
- Runtime-built UI cannot use `%UniqueName` until `owner` is an ancestor already in the tree. Keep member refs or `find_child(name, true, false)`. `Camera3D.look_at()` also requires in-tree; use `look_at_from_position()` while assembling a SubViewport.

### Packaging and generated files
- Godot 4.7 export-pack writes PCK format v4. Parse `dir_offset` after `file_base`. Required shipped files may appear as `.import` / `.remap` / `.gdc` or `.godot/imported/<basename>-<hash>.*`.
- Do not overwrite `build/act1/rr.dmg`. That path is the frozen Act 1 SHA bind. Use `build/inventory/` for after-packs.
- After `generated/.gdignore`, burgher rebuild-brief tests must `FileAccess.open(ProjectSettings.globalize_path(path))`.
- Act 1 packaged smoke can print `P3-012_PACKAGED_PLATFORM_PASS` and still emit Compatibility RID leak noise. Treat that as non-blocking in `tools/verify_act1_release.sh`.
- Blender-authored generators import `bpy`. Invoke them through Blender's bundled Python, not repository `python3`.
- Blender glTF export with packed textures still yields Godot-extracted `*_albedo.png` / `*_normal.png` / `*_roughness.png` sidecars. Register those derived paths in `assets/SOURCES.csv`.
- When `git push` ends with `broken pipe`, compare `git ls-remote` with local `HEAD`. If GitHub SSH port 22 is closed, retry once through `ssh.github.com:443`.
- A runtime script error in a headless SceneTree probe stops before `quit()` and hangs the process. Always wrap probes in a watchdog. Imported PNG texture arrays load as `CompressedTexture2DArray`, so type them as `TextureLayered`, not `Texture2DArray`.
- Before implementing contract physics literally, check sign conventions against an observable property (for example, the Jacobian must drop on crests so foam sits on crests). Record any deviation in the contract's final-parameters section and the output manifest.
- Float LUTs (EXR) import Lossless as `RGBAH`, but also set `detect_3d/compress_to=0` in the sidecar. Otherwise the first 3D use switches them to VRAM compression, which wrecks small HDR values. Assert `Image.get_format()` is a float format in a test.
- When porting a third-party LUT parameterisation, check that the forward lookup and the bake's inverse round-trip before copying either. Tidewater's transmittance sub-UV does not (W/(W+1) vs W/(W-1)). A ray that starts exactly on a sphere can report a -1 miss from rounding, so clamp integration lengths at 0.
- A SubViewport LUT sampled by a 3D/sky shader: index texels with `FRAGCOORD.xy / size` in the canvas kernel, not `UV`, so memory order matches `texture()` on every backend. - Godot 4.7 `AnimationPlayer`: a paused player (or one at `speed_scale` 0) does not apply a `seek(t, true)` pose, so clock-driven clips freeze at their blend-in pose (R-1161 hammer swing). Keep the player playing and call `seek(t, true)` + `advance(0)` every frame; still captures switch `callback_mode_process` to `ANIMATION_CALLBACK_MODE_PROCESS_MANUAL` instead. Presentation tests must measure bone poses (`get_bone_global_pose`), never only computed seek times. Cross-fades advance on the idle frame, so an end-to-end check that loops `_physics_process`/`_sync_player` without engine frames sees the idle pose forever (false "frozen swing"); either play with blend 0 or `await tree.process_frame` (see `test_combat_animation_runtime.gd`).
- Focused tests that call `Player._physics_process` in a loop run inside one engine frame: `Input.is_action_just_pressed/just_released` stay true for every call (both at once after a press+release), and `move_and_slide` uses the idle frame delta (often >0.1 s) instead of the physics step. Hand input edges out once per `Engine.get_physics_frames()` (`PlayerActionInput._consume`) and derive scripted velocity from the step `move_and_slide` will actually use (`Player._slide_exact`).
- `MapView3D`'s camera is orthogonal: zoom is `camera.size` (it defaults to the whole map diagonal), and moving the camera along its own axis changes the framing not at all. A capture tool that wants one channel, street or building to fill the frame must set `camera.size`, then place the camera so the subject is at the centre.
- `tools/godot_render.sh` sometimes returns a whole run of byte-identical plates: the minimized window stops redrawing and every shot is the first frame. `md5` the shots before reading anything into motion or framing; re-running the same command clears it.
- When a delegated Docker agent fails within seconds with "empty final response", run `df -h /System/Volumes/Data` before retrying: a full host disk kills child sessions silently (and later breaks local tool output with ENOSPC). Do not retry the delegation blindly; do the work locally and report the disk state to the user.
- MultiMesh instance transforms are not readable on the headless dummy renderer (`get_instance_transform` returns identity), so a query over instances passes or fails by accident in tests. Keep the transforms you placed as node meta (see `TreeLeafFall3D.tag_canopy`) and query those instead.
- Running a non-`SceneTree` script with `--script` to expose its parse error never exits once it parses cleanly. Run it in the background and kill it, or run the `SceneTree` tool that depends on it.
- The shared `stone` role material texture is itself painted as coursed blocks. On geometry that already models individual stones it doubles every joint, so use tinted `MapViewMaterials.natural_rock()` grain for modelled masonry.
- Terrain is opaque at y = 0, so shafts and pits below ground cannot be real geometry. Cover the mouth with a disc whose shader ray-traces the hole in model space (see `map_view_well_shaft.gdshader`), and verify both the perspective and the orthographic camera branch.
- MultiMesh copies of an animated actor freeze in whatever pose was baked. Bird flock followers glided rigid for months behind a flapping leader. Animated instanced crowds need a per-pose flipbook (one renderer per pose, actors moved between them each frame) or vertex animation, and the test must sample several frames and assert that instances change pose.
- Burgher-house kit GLBs join every part per material in `House.finish()`, so a baked part cannot be hidden or animated alone at runtime (the hoist hook sat inside the wrought-iron mesh). Anything Godot must animate or replace gets a `House.marker()` empty in the GLB plus runtime geometry (see `MapViewHoistRope.attach_at_markers`).

- For atlas cut-out tests, inspect `Texture2D.get_image().detect_alpha()` rather than `has_alpha()`: imported GPU-compressed textures can report no alpha through the latter despite retaining cut-out texels. Relative-brightness atlases are data, not `source_color` samplers; resize already-premultiplied pixels channel-wise to avoid Pillow RGBA double-premultiplication.
- Magic/particle VFX must be judged on rendered plates (`tools/capture_magic_vfx.gd`), not headless tests: every R-1198 defect passed the test suite. Recurring traps: maps have no reflection probes, so `METALLIC` above ~0.6 renders black (fake the sheen in `EMISSION`); dozens of overlapping additive quads saturate to flat white, so explosion ramps need low per-particle alpha; big billboards slice hard edges into the ground without `proximity_fade_enabled`; world-space trails on a fast emitter bead at the default `fixed_fps = 30` (use 0); a sweep shader's leading-edge band must fade out at full coverage or it parks on the crown.
- A map-level "no vegetation inside prop X" guard can be vacuously green: probe it by stripping `definition.props` (so `prop_cell_rects` returns nothing) and counting instances that land in the real rects. On `market_civic_quarter` both the scatter and the first-person cover placed zero tufts in the prop rects even with the exclusion disabled, because the prop had since moved onto bare market floor. Keep the map guard, but prove the fix on a synthetic planted meadow (bare count > 0, dressed count 0) and say in the test which assertion is the proof and which is the invariant.
- Scatter and dense ground cover are two independent layers (`map_view_mesh_builder_scatter.gd`, `map_view_terrain_details.gd`). A cell-exclusion fix applied to one leaves the other growing through props; eye-level screenshots show the cover layer, which is the one players report.

- Alpha-scissor foliage atlases: a white outline means light RGB in edge texels (mips blend it in). Erode alpha and repaint non-solid texels with nearest leaf colour (`tools/assets/defringe_atlas.py`) instead of only keying the backdrop.
- A scene that instances realistic-human rigs and is torn down with a direct `free()` (tests do this) logs dummy-renderer `material_get_instance_shader_parameters: Parameter "material" is null` errors, which fail every test that frees it: the rig only detaches geometry when `is_queued_for_deletion()`. Detach in the owning scene's `_notification(NOTIFICATION_PREDELETE)` with `SharedCharacterRig._detach_render_geometry(self)` (script PREDELETE runs before Node frees the children; see `AlmshouseStage`).
- Default gamepad slots collide with combat verbs: `spellforge_element_3/4` are the same shoulder buttons as `player_guard` / `player_dodge`, and `_1/_2` are X/Y (attack). Any screen that reads both a slot action and a defence action in the same frame must drop the slot press when `InputMap.action_has_event` says the event also belongs to the defence (see `SpiritArenaHost._shares_defense_binding`). Keyboard-only tests never catch this; assert on the spent resource after a simulated pad press.
- An HBox card with `[icon][name expand+clip][binding label]` silently eats the name: a binding label like "3 / Left Shoulder" leaves a few characters and the capture shows `[S|`. Put only the keyboard key in the badge, wrap the name (`AUTOWRAP_WORD_SMART` + `max_lines_visible`), and move the full binding to the tooltip. Always read the render capture, not just the green tests.
- Mounting a glb on a rig: check whether its meshes have a `skin`. A skinned glb (kettle hat, clothes) goes through `rig.equip_garment(id, scene)`; `rig.equip(slot, scene)` puts it on a bone attachment at the bone origin, so a body-space model floats a body-height above the head. `PackedScene.pack()` of a node tree whose children have no `owner` silently packs nothing, so never wrap a glb instance in a throwaway holder to make an equip scene.
- A hand slot's local axes are not world axes (`handslot.r`: X points down, Y forward): measure the basis on the idle pose in a headless probe before hand-tuning a held prop's transform, then confirm on a render plate.
- Before wiring a clip into a per-event sound pool, check its duration. A multi-second *walk cycle* (`sounds/walk_wood.mp3` 5.0 s, `sounds/walking_on_mud_stable_audio_3.mp3` 8.0 s) played per foot plant stacks `max_voices` overlapping loops that keep sounding after the player stops; the whole 20-terrain fallback chain funnelled into it, so every map was noise. One-shot pools need a duration cap in the validator, not a listening pass to catch it.
- ffmpeg `-ss` *after* `-i` discards frames after filtering, so the filter graph still sees the whole stream: `afade=t=out:st=...` then times the fade against the original clip and the kept region comes out silent. `-ss` before `-i` is tied to the frame grid. Cut inside the chain with `atrim=start=..:duration=..,asetpts=PTS-STARTPTS`.
- Normalise short one-shot pools on RMS (`volumedetect` mean_volume), capped by a peak ceiling, not on peak alone: impacts differ in length, so peak-matched variations still jump in loudness. Leave ~2.5 dB under the ceiling for MP3 encoder overshoot.
- `csv.writer` defaults to CRLF. A generated `manifest.csv` then reads back as modified after every regeneration; pass `lineterminator="\n"`.
- A second copy of a `.tres`/asset under gitignored `build/` squats its `uid://`, and the next import silently reassigns a *new* UID to the tracked file. If a restored resource comes back with a changed UID, delete the stale copy first, then re-import.
- Keep required runtime resources out of `/build/` (gitignored): `project.godot` pointing `buses/default_bus_layout` at `res://build/...` leaves a fresh clone, CI and the export with no audio buses, and Godot then routes every sound to `Master`, past the volume sliders.
- A placeholder sound may stand in for a *missing variation*, never for another material. Pointing stone and sand footsteps at the wood pool and grass at the mud pool passed every test and the coverage gate, and the first player report from `world_saaremaa` was "horrible noises": beaches knocked like planks, meadows squelched like a swamp. Listeners identify surface type instantly, so a wrong type is heard as a defect while a missing step is not. When no material-correct pool exists, resolve to silence, or synthesise the material in-house (`tools/audio/generate_footstep_oneshots.py`).
- A "no surface may be silent" coverage test rewards cross-material substitution: it is green exactly when something plays, right or wrong. Assert instead that the resolved ID names the requested material, and let silence be a legal result.
- Gain to an RMS target and then limit, rather than backing the gain off to fit a peak ceiling, when the pool is synthesised: a synthesised impact has a much higher crest factor than a sliced recording, so a peak-capped gain leaves it ~5 dB quieter and the player hears the level drop when crossing from one surface to the next.
- `python3 -I` drops the script's own directory from `sys.path`, so repo tools that import a sibling module (`tools/validate_asset_sources.py` -> `generate_asset_inventory`) fail with `ModuleNotFoundError`. Use `-I` for untrusted downloaded data, not for this repo's own tools.
- The commit hook runs `gdlint` on staged `.gd` files, and it is stricter than the parser: max line length 100, `enum` before `const` in the global scope (`class-definitions-order`), and no unused function arguments. Run `python3 -m gdtoolkit.linter <files>` before staging a new script; `gdlint` itself is not on PATH. When shortening a long arithmetic line, split it across lines inside one parenthesised expression rather than hoisting a sub-expression into a variable: regrouping `a * b / c` into `t = b / c; a * t` changes float rounding, and a deterministic-mesh test will not catch it because both builds in one run agree.
- A test can pass on the implementation it is meant to prove and on the one it is meant to reject. Before trusting a new behavioural test, run it against the old code path (a temporary `if false and ...` on the dispatch): if it stays green, it is an invariant guard, not a red/green proof - say so in a comment and name the test that does discriminate.
- Do not mark one mesh among many that share a ShaderMaterial with an `instance uniform`: in GL Compatibility every instance of that shader (all ~300 city terrain chunks) takes a slot in the global shader-parameter buffer and it overflows ("Too many instances using shader instance variables"). Mark the special mesh through a vertex attribute instead: meshes without a COLOR array read COLOR as white, so `COLOR.a = 0` on the one mesh is a free flag.
- In GL Compatibility `RenderingServer.viewport_get_measured_render_time_gpu` returns 0. To compare GPU cost of a change, time frames by wall clock with `viewport.get_texture().get_image()` after `frame_post_draw` (the readback waits for the GPU) and toggle the feature in the same run; for vertex-heavy meshes measure a coarser variant before tuning shaders, because vertex count was the whole cost of the trail relief mesh.
- `ls` in this shell prints coloured columns (permissions, size, date), so `ls | sed` builds garbage lists; a bad `--filter=` to `run_godot_tests.gd` then matches nothing or runs the whole suite. Use `/bin/ls` inside the directory for file lists.
- City capture of a weather effect tied to a cloud cell (rain shaft, shadow, strike): do not move the camera to the cell centre, which is usually outside the town, over sea or inside the terrain (plates come out underwater or flipped). Keep a known open camera spot (above the roofs) and shift `sky._cloud_offset` by `wrap_delta(eye, cell) / CloudCells.METRES_PER_UV` so the cell drifts over the camera; cells are a pure function of the drift. A street-level eye at a guessed coordinate also often lands inside a building.
