# Art playbook

Read `agents/playbook.md` first for shared workflow, tooling, and Git lessons.
This file contains lessons specific to the Art role.

## Role-specific lessons

### Capture and tooling
- Headless dummy rendering cannot read a SubViewport texture. Run captures via `tools/godot_render.sh --script <tool>.gd` (real GPU, no visible window) and verify PNG header and dimensions.
- Host Blender 5.2 exposes EEVEE as `BLENDER_EEVEE`, not `BLENDER_EEVEE_NEXT`. Factory-startup may leave `scene.world` unset; create an explicit world before writing world color.
- Blender's bundled Python often lacks Pillow. Compose contact sheets with host `python3` after Blender writes per-species previews.
- `blender_run_script` may not mount the project at `/workspace`. Pass absolute GLB paths to `bpy.ops.import_scene.gltf`.
- Blender `mathutils.Vector` uses `(a - b).length`. Flatten matrix rows before scalar comparison. `bpy_prop_collection` does not support non-unit slices.
- Blender-authored generators import `bpy`. Invoke them through Blender, not repository `python3`.
- When Leonardo, ComfyUI, or Hunyuan3D is unavailable, ship deterministic Blender generators instead of blocking. Leonardo may reject an unsupported `preset_style`; retry with the field empty.
- Leonardo's configured realism model still defaults to modern lawn, hardwood catalog, regular setts, hexagonal dry mud and woven mats. Name those product categories in the negative prompt and require soil, wear or mixed sizes as a large share of the plate. Even then, stone families usually stay CG pavers: keep the P0-218 procedural cobble shader instead of wiring a rejected plate.
- Cursor CLI does not expose `leonardo_generate_image`. Call Leonardo REST through `tools/generate_leonardo_material.py` and store the full prompt in `prompt.json` beside the plate. The CDN returns 403 to bare urllib; send a browser User-Agent.
- Do not downscale authored grass or mud into the 128 px terrain array. Sample those plates at native 512 px. The shared array stays small so procedural families do not pay a 16x paint cost.
- City walls need coursed limestone rubble, not the even ashlar `stone` family. Keep the generation prompt with the plate so the next pass can sharpen joints instead of guessing.
- Do not half-tile-offset a coursed masonry, board, or large-stone plate before welding. That move puts the original wrap seam across the middle of the wall face, splits floorboards, or stamps a diamond into cobble.
- Extra house wall/roof maps belong in `assets/materials/pbr/building_variants/` from `tools/generate_building_surface_variants.py`. Do not mutate imported GLB materials; duplicate onto surface overrides keyed by stable building id.
- Never open `assets/SOURCES.csv` with mode `w` until the replacement row list is fully built. Prefer write-to-temp then rename. Parse with `csv.DictReader`. The primary key is `asset_id`; SHA-256 belongs in `prompt_or_url`.
- After adding fauna or prop GLBs, run a headless Godot import before tests. Update bird authored-mesh allowlists in the same change as new `assets/birds/**` GLBs.
- Licensed authored fauna under `assets/animals/<vendor>/`, modular facade GLBs under `assets/buildings/facades/`, and furniture, crafts, or environment GLBs under `assets/props/furniture/<stem>/`, `assets/props/crafts/<stem>/`, or `assets/props/environment/<stem>/` should use one subfolder per model (for example `hendrik_reyneke/chicken/`, `facades/timber_window_open_shutters/`, `furniture/smithy_bed/smithy_bed.glb`, `environment/sacred_grove_ancient_oak/sacred_grove_ancient_oak.glb`), mirroring `assets/birds/<species>/`. Move each GLB with its Godot sidecars together, then update `assets/SOURCES.csv`, every relocated `*.import` `source_file`, and hard-coded paths in generators, showcase, evidence, and tests. For furniture, crafts, or environment props, run `python3 tools/assets/relocate_furniture_per_model.py`, `relocate_crafts_per_model.py`, or `relocate_environment_per_model.py`, then fix `Path(...)` OUTPUT constants in the Blender generators. When bulk-rewriting paths programmatically, scope the file walk to the tree being moved and skip `.worktrees/` and `build/`. After moving environment GLBs, run headless `godot --import` before tree-species tests.
- Verification-only captures can overwrite tracked evidence PNGs. Check `git status` immediately and restore pre-existing outputs before committing.
- When retiring a duplicate character body, search both catalogue and live-integration tests: the live rig may already use a differently named replacement and its own wardrobe. Update tests to assert the active body, and do not recreate deleted fitted gear just to satisfy stale assertions.
- When cleaning generated assets, remove only the exact newly created paths. A broad glob can delete another worker's artifacts.
- Batch runtime GLB cleanup uses `tools/assets/cleanup_runtime_glb.py` after a JSON-chunk audit (`tools/assets/glb_runtime_audit.py`). Blender's glTF importer can fabricate a phantom `Icosphere` that is not in the file; do not re-export those. Decide helpers from node/object names, not mesh datablock names: songbird `Leg_L` keeps data named `Cylinder`, and KayKit cape/shield keep `Plane.NNN` / `Cylinder.NNN`. Treat `Icosphere`/`Camera`/`Light` (any suffix) and only exact unused `Cube`/`Plane`/`Cylinder` objects as helpers. After a real helper is removed, snap livestock/fauna to Z=0; do not independently snap shared-rig character LOD GLBs, because `SharedCharacterRig` remounts those meshes onto the live skeleton. Verify helpers from the GLB JSON chunk or Godot ground-contact tests, not a Blender re-import.

### Procedural trees
- When a species looks wrong, first check which generator grew it: `TreeSkeletonWeberPenn.has_preset` false means the legacy recursive skeleton (pole, top tuft, two arms) no matter how its profile is tuned. Compare the whole catalog sheet against photos of the real habit, not only the species named in the complaint.
- `MapViewMeshBuilderMath.hash01` returns 0..1 inclusive. Clamp anything that must sit strictly inside (0, 1), such as the card leaf seed, at the point of use; nudging a preset until the edge case disappears only hides it.

### Diagnosing a rendering artifact
- Identify the offending surface before editing anything. Three debug renders answer almost every "what is that?" question, and each costs one capture run: replace `ALBEDO` with a constant (artifact gone means it is albedo, not lighting or geometry), enable `Viewport.DEBUG_DRAW_WIREFRAME` (shows whether the shape is one mesh, a decal quad, or a MultiMesh), and write the suspect values into `EMISSION` channels with `ALBEDO = vec3(0.0)` so a script can sample exact values from the PNG.
- Do not confirm a suspect material by setting its albedo uniform to magenta. A transparent overlay that derives its colour from `EMISSION` or from a screen sample ignores albedo entirely and stays innocent-looking. Force `EMISSION` instead.
- Hard-edged triangular wedges in ground or terrain are a `flat` varying, not a texture. Layer indices that are flat per triangle while the blend weight interpolates make the provoking vertex paint the whole triangle; no fragment-side noise, contrast or tone change can remove them.
- A node dump that walks `MapView3D` children misses terrain and scatter: chunks are built on demand and are not in the tree until the viewport has rendered. Dump from inside the capture tool after the warm-up frames, and handle `MultiMeshInstance3D` separately from `MeshInstance3D`.
- `hint_screen_texture` is unreliable for transparent decals under the shipped GL Compatibility renderer; it returned white and turned puddles into pale shards. Prefer a darkening film plus fresnel sheen, which is also cheaper than a per-decal back-buffer copy.

### Material scale
- Derive tiling from the physical size of the thing, not from what looks busy. One world unit is about 0.87 m, so a limestone rubble course is about 0.3 m and a brick course about 0.1 m. The masonry repeats before P0-218 packed roughly six times that many courses into a wall, which is exactly what makes stone read as printed wallpaper.
- Flat surfaces without a normal map are the main reason large architecture looks like painted cardboard. `Image.bump_map_to_normal_map()` on the same grayscale plate that produced the albedo is enough, and its cache key must include the plate seed and size.
- An authored RGB plate excluded from palette tinting will drift out of the value range of everything it borders. Either tint it or check its lit value against its neighbours.

### Character skin projection
- Per-face front/back material switches on a single mesh leave a torn silhouette seam and smear reference plates across every side-facing surface, because planar XZ projection collapses texel density wherever the normal turns away from the camera. Bake one smart-projected atlas instead: blend the original plates per texel by a cubed facing term, diffuse low-confidence grazing texels, and retire the old projection sidecars in the same change as the GLB rebuild.
- Locomotion that only keys hips and a flat shoulder swing reads as a mannequin slide. Conjugate lower-arm rotations through each shoulder's rest drop so elbow keys hinge correctly, and ground each cycle with sole probes plus a pelvis offset so the lowest heel/ball/toe contact stays on the floor.
- Diffusing a texture fill across an unwrapped atlas in UV space cannot work: islands are packed arbitrarily, so a texel's neighbour may be hair, an unrelated limb or background, and relaxation that averages uncovered texels drags island borders to black. Bin by world position and weight every contribution by the facing term instead.
- Which arm folds matters. In a run the lead arm closes toward the chest and the trailing arm opens behind the hip; fold them the other way and both hands park in front, which `test_character_rig` catches as a contralateral-swing failure.
- Ankle and toe rotation ride the same sine as the hip, not a quarter-cycle cosine. On a cosine the foot is neutral at both heel strike and toe-off and points through mid-stance, so the character walks on its toes. Render the cycle over a floor plane; foot contact is not judgeable against empty background.
- Do not run a blanket `vertex_group_smooth` over a heat bind on a clavicle-less skeleton. It spreads chest weight onto upperarm and back, `bind()` then keeps only the four largest influences, and the shoulder tears open along a hard crease. Judge such a change by rendering an unchanged CC0 clip before and after, and by the mean pixel delta, not by eye.

### Materials, export, and provenance
- Blender glTF export with packed textures still yields Godot-extracted albedo, normal, and roughness sidecars. Register those derived paths.
- A material created via `bpy.data.materials.new()` has `use_nodes = False`. The exporter then writes default grey. Untextured materials still need Principled BSDF.
- Vertex colours reach Godot only through COLOR_0. Export all sets and promote the real set after export. Verify on the Godot side (`ARRAY_COLOR` plus `vertex_color_use_as_albedo`). Do not assign a surface-override material for headless livestock tests; the dummy renderer reports that override as null.
- Character glow under MapView bloom is usually ORM roughness G=0 or `KHR_materials_unlit`. Repair with `tools/repair_character_orm_normals.py`. Sketchfab game-ready coats often ship unlit.
- Smart-projected livestock UVs plus a Cycles emit bake can turn horns, udder, and mane into a dot grid. Paint those regions as COLOR_0.
- A material name missing from the generator palette silently falls back to `outerwear`. Add palette, roughness, and specular entries with the geometry.
- Do not delete Godot-extracted character PNGs until GLB images are URI-linked. After the switch, tests must match `hero_tex_` shared stems.
- Rights-blocked media: preserve the verified fallback. Never download or register an asset from metadata or a CC BY-NC page alone.

### Anatomy and generators
- Quadruped gait bounce in `import_realistic_mammals.py` must only sink the trunk below rest. Sourced forelegs stand near full extension, so a body rise at touchdown leaves the paw out of reach, and `reachable_*` silently shrinks the stride until the legs barely move. Mirror the Godot test contracts inside the builder: always keep at least two paws planted in Walk/Run, and probe the pad contact point for ground penetration. Ramp swing-paw folding with the same sin^2 curve as the lift. Render a side-view before/after sheet over a floor before publishing.
- Shared quadruped livestock GLBs face -X. Fix `MODEL_YAW` before rebuilding `dimensions_m`. Measure world height through the actor host transform, not the raw mesh AABB.
- Joined procedural volumes without voxel remesh ship as a bubble cloud. Remesh and unify-smooth before rigging. Start legs inside the barrel. Keep ears inside the skull height budget.
- Facial detail spheres must snap to the remeshed surface. Claws and eyes authored in pre-normalize world space float after `normalize_dimensions`.
- Palmate antlers remeshed with the hull fuse into the scapular hump. Keep body-only remesh and parent palms as detail meshes.
- Sparse sphere tails remesh into beads. Keep a continuous overlapping spine. Measure coat `side_ratio` from body-only width.
- `create_quadruped_rig` places pupils 1.5 cm in front of the socket. Author small-skull eyes manually.
- Do not sit catalog scapular cards proud of a bird hull. Do not add an 11th argument to `curve_tube`; gdlint caps functions at 10 arguments.
- Bone-level proportion changes shift `BODY_STATURE`. Update `SharedCharacterRig.HEROIC_MODEL_SCALE` to `2.0 / BODY_STATURE` and regenerate LODs.
- Iterate character pose work on the skeleton intermediate plus a numeric audit. Only run the full body rebuild once the numbers land.
- Indoor wall banners hang from a wall-parallel top rod with UV.y hem sway. Banner cloth authored in XY with a -Z lit face needs `rotation.y = +PI/2`.
- Render every component of a procedural prop kit before shipping it. Primitive-assembly generators emit numerically valid but physically disconnected parts: levers extruded along the wrong axis, roofs seated above the wall head they should rest on, repeated elements spaced along their own length so the array collapses into one clump. A clean export, a component count, and a green self-check prove nothing about whether the pieces touch.
- Assert kit invariants inside the generator, not only in its report. A report field that records `ground_contact: false` and still writes the GLB will ship a prop that sinks through the map floor.
- Sketchfab CC BY downloads need a logged-in session or API token; the agent browser cannot fetch them. When replacing a licensed-source mammal, confirm license/metadata via the public `api.sketchfab.com/v3/models/<uid>` endpoint, then ask the maintainer up front to drop the GLB into `~/Downloads` (or provide a token) before starting pipeline work.
- Every CC BY model must reach the in-game Credits screen. Record `title`, `author`, `url` and `license_url` in `assets/storybook/mammal_sources.json` (or `LEGACY_MODEL_CREDITS` in `tools/generate_credits.py` for non-mammal imports), then run `python3 tools/generate_credits.py`. Never hand-edit `CREDITS.md`; the generator overwrites it.
- P0-183 runtime GLB caps live in `docs/data/runtime_glb_budget.json` and `tools/verify_asset_lint.py`. When Godot already extracted sibling PNGs from a landmark GLB, URI-reference those files instead of keeping BIN embeds; that dropped the Sacred Grove oak 10045452 -> 7868736 bytes with unchanged triangles. Shared character LOD0/1/2 already URI-share `textures/`. The default `assets/**/*.glb` cap is 10 MiB minus one byte until storybook mammals (rat ~9.9 MiB) are reduced (**P0-183b**). Do not set the default to 8 MiB while those files remain.
- Blender's glTF exporter only writes a bmesh colour layer as `COLOR_0` when that layer is the mesh's active and render colour attribute. Otherwise it emits a white `COLOR_0` and demotes your layer to `COLOR_1`, which Godot ignores. Set `color_attributes.active_color` and `render_color_index` after `to_mesh()`, then check the GLB accessor before you trust vertex alpha.
- Rim-faded ground dressing (shingle, wrack) needs `TRANSPARENCY_ALPHA` and a slope-aligned, lifted transform. Alpha hash renders as a hard cut-out on Compatibility, and a flat mesh laid on relief gets clipped by the terrain into a crisp edge. Anything seen through the WS-13 underwater pass must stay opaque or alpha-scissored: that pass composites from depth, and blended surfaces vanish there.
- Seat sea props on the rendered bed (`field_height - basin_extra_depth`), then check how far each one emerges. The WS-13b basin is about 0.8 units deep 2 cells off the line, so a contract-size boulder is fully drowned and invisible from the gameplay camera. Choose the variant by emergence.
- A half-tile phase shift plus edge weld does not make a non-tileable AI plate seamless. It moves the original seam into the middle of the tile, where it repeats as a cross grid across large ground areas. For isotropic ground, cut a smaller tile, quilt its wrap edges from the leftover plate strips along min-error cuts, and resize with wrap padding (`SEAMLESS_FAMILIES` in `tools/process_leonardo_terrain_textures.py`). Check tileability with a 2x2 tiled preview before you ship.
- An AI terrain plate also carries the generator's one-sided lighting. That broad gradient survives quilting and repeats as a blotch grid over large ground, which reads exactly like a tiling seam. Divide the low-frequency luminance out in linear light before quilting (`_flatten_lighting`), keep a residual fraction so the ground is not flat, and rederive normal/roughness from the corrected albedo. Score a plate with two numbers - wrap-edge and worst interior column/row discontinuity, both normalised by the mean neighbour-pixel difference - because a welded border scores a perfect 0.0 while the real seam sits in the tile centre.

### Authored interiors
- Board and plank plates cannot quilt across the boards: a min-error cut through a gap smears it. Crop the tile gap-to-gap so the cross-grain wrap lands on a real gap, cross-fade only the along-grain wrap, and divide out the generator lighting first (`BOARD_FAMILIES` in `tools/process_leonardo_terrain_textures.py`). The crop changes boards per tile, so rescale every consumer's UV density to keep the board width.
- Wood plates (timber, floorboards) carry grain along V. Under world triplanar the grain runs one fixed world direction, so boards laid across it read as a checkerboard and beams show cross-grain seams. Give wood grain-aligned UVs in metres (V along each face's longest edge) and keep triplanar for masonry, plaster and earth.
- Before retuning a warm-looking interior material that renders blue, check the environment: enclosed rooms inherit sky-tinted ambient and sky reflections. Metals and water mirror the sky dome unless reflections are disabled indoors.
- A subtle COLOR_0 recipe looks exactly like "vertex colours not applied". Confirm the colour array and `vertex_color_use_as_albedo` on the imported mesh at runtime before debugging the exporter, then strengthen the recipe.
- Tinting a smooth plaster plate brown does not make a floor: it reads as paint. The yard mud plate reads as wet ruts indoors. Beaten-earth floors need their own plate (Leonardo, quilted seamless) plus vertex-colour dust.
- Room shells and interior dressing are props, not ADR 0025 buildings: GLBs under `assets/buildings/` must declare a tier and LOD budget. Put them under `assets/props/architecture/interiors/<stem>/`.
- Godot multiplies `roughness_texture` into the `roughness` scalar. Keeping a hand-picked scalar next to a roughness plate halves the plate's values and lacquers every surface: a 0.42-average timber plate at `roughness = 0.82` renders at 0.35. When a plate is bound, set `roughness = 1.0` and let the plate govern, as `MapViewMaterials` already does, and drop `metallic_specular` for anything that should never look polished.
- A saturated key light silently destroys hue on dark materials. The forge fire at (255, 140, 52) drove the bellows leather's green and blue below one 8-bit step, so the bag rendered as a flat red-black blob while the stone beside it looked fine. Judge a warm interior by sampling channel ratios in the capture (`G/R`, `B/R`) against a neutral reference surface in the same frame, not by eye - then fix the light's spectrum before repainting the material, because every dark prop near that light has the same problem.
- Floor dressing placed against the far wall is invisible in play. At the shipped dimetric camera pitch a 3.75 m wall head hides roughly the last four floor rows, so a bench or heap flush to that wall only ever shows in close-camera mode. Place gameplay-readable clutter at least four cells in from the far wall and confirm it in the top-down crop, not only in a first-person shot.
- AR-03 library tints carry hue only (`_library_tint` normalises by the peak channel), so a darker `wall_color`/`roof_color` does not age a surface. To dull a landmark material, pin its stem with `library_surface_for_building` under a landmark-only prefix and multiply both `albedo_color` and the `ar03_base_tint` meta. Staying in the AR-03 cache keeps it under the anti-tiling toggle and `reset()`.
- The procedural gabled roof closes its gables with a tile face at `ROOF_OVERHANG` beyond the wall. A stone gable placed on the wall plane is hidden behind it. Build the gable as a prism that reaches past the overhang, and cap it with a gable course and coping.
- Node-existence tests do not prove that a procedural landmark's details are visible. The R-281 St Olaf tower stood lower than the nave ridge, and its lancets and buttresses sat inside the wall box, so for weeks the church rendered as a plain barn with a green test. Assert geometry against the mass (the tower top above the ridge, openings on the wall face, every mesh AABB inside the footprint), and review a studio plate of the building alone (`tools/capture_st_olaf_1343.gd` pattern) before trusting an in-map view.
- Double-sided procedural meshes (`cull_disabled`) must still wind every triangle to face its authored normal. Godot flips `NORMAL` on back faces, so a quad wound against its normal is lit as if seen from below. Every bird feather card was wound that way for months, and wings read darker and flatter than bodies without any test failing. Check with a capture that paints one side red, and choose corner order from `(p1 - p0).cross(p2 - p0)` against the normal (Godot front faces are clockwise).
- A straight card laid between two points of a cambered surface sags through the arc and disappears under it. Lift such cards above the surface by about the arc's sagitta, or they silently stop contributing to the silhouette.
- OpenAI `gpt-image-1` credits can run out mid-batch and the Leonardo.ai fallback is not a drop-in: the same prompt yields softer frames, people who stare down the lens, and confident anachronisms (glass lanterns, louvred shutters, storm-drain grates, trench coats, lace-up boots, overhead wires). Budget two or three passes per Leonardo frame, name each figure's position in the frame, say "nobody looks at the camera", cut the crowd (four figures succeed where a market square fails), and list the wrong century and the wrong geography explicitly in the negative prompt. Mark fallback frames `provisional` in `assets/SOURCES.csv` and keep the final prompt in the record so a regeneration reproduces rather than reinvents. Full grammar: `cinematics/PROMPT_GRAMMAR.md`.
- `tools/generate_leonardo_v2_image.py` turns an exhausted Leonardo balance (HTTP 402 `Insufficient tokens`, returned as a JSON list) into a `TypeError: list indices must be integers` traceback, and eight parallel requests can drain the balance mid-batch. Read the raw response before retrying, and generate a plate set sequentially or with a known budget. Nano Banana also invents pseudo-lettering on tituli and banderoles even with "no text" in the prompt: check every plate for letters and paint them out (record it in the `edits` column).
- Check the image budget before planning a plate set: `GET https://cloud.leonardo.ai/api/rest/v1/me` (`apiPaidTokens`; a Nano Banana image needs far more than single digits), the OpenAI tool's first call, and `curl 127.0.0.1:8188/system_stats` for ComfyUI. When all are dry, draw geometric ornament (consecration crosses, dado curtains, foliage bands, masonry lines) procedurally with numpy + Pillow (`tools/build_church_mural_plates.py` pattern: fixed seeds, x-periodic noise for tiling, `--check` mode) and split figural subjects into a follow-up instead of blocking the whole task.
