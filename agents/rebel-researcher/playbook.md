# Researcher playbook

Read `agents/playbook.md` first for shared workflow, tooling, and Git lessons.
This file contains lessons specific to the Researcher role.

## Role-specific lessons
- Before editing from a summarized audit, re-read the exact target line; a stale assumption can turn an already-correct permission into a failed replacement.
- When downloading research papers, verify the response MIME/file signature before passing it to PDF tools; OJS download links can return an HTML interstitial, so resolve the actual article-download URL first.
- Verify downloaded research-source MIME type and file signature before treating a download endpoint as a PDF; OJS and museum endpoints can return HTML viewers or interstitial pages.
- When web-search wrappers return truncated payloads or quota errors, pivot to direct official pages and scholarly sources, then state the evidence boundary instead of repeatedly retrying broad search.
- `python3 tools/verify_historical_dossier.py` currently fails on the pre-existing registry-map coverage gap (`holy_spirit_church` and `oleviste_church` missing dossier cards); keep this baseline failure separate from scoped dossier/plate verification.
- When an archive download endpoint returns HTML instead of the advertised file, verify the response MIME type and file signature before using it as evidence; prefer the repository's API content route or cite the catalog record and preserve the access limitation.
- When a research task finds a regionally correct media page without an explicit commercial license, treat it as a rights blocker: preserve the verified fallback, record the exact source URL and permission path, and never download or register the asset from metadata alone. If an external page also has TLS or API access errors, record that as evidence but do not treat it as permission.
- For rights-blocked media tasks, preserve the verified fallback and record access failures (rate limits, bot challenges, HTTP errors) as an evidence boundary; never substitute metadata, regional relevance, or an NC license for explicit commercial permission.
- For rights-blocked bird-audio integration, keep the existing commercial-compatible fallback unchanged when the regional candidate is metadata-only or CC BY-NC; record the exact source/permission boundary and create a permission-cleared follow-up instead of changing curated rows.
- A permission-cleared regional audio replacement cannot be completed from metadata or a non-commercial page: preserve the verified fallback, record the exact rights boundary, and hand off to the existing human-outreach task before changing the curated row or registering audio.
- Research dossier reciprocal-link edits need the exact live line re-read after summarized grep; similar-looking cross-reference text can differ by path depth or punctuation and make a targeted replacement fail.
- Direct DOI/handle fetches may return 403/500 even when indexed scholarly metadata is available; use the indexed abstract as comparative evidence, record the access boundary, and do not repeatedly retry broad fetches.
- A dossier-specific smoke check should validate required sections and evidence labels actually used by the dossier, not require every possible confidence category to appear in every file.
- The task board replaced the legacy `TODO.md`, so research-index link checks may report that pre-existing path as missing; exclude that known legacy link when validating a scoped dossier rather than widening the research task.
- When a research PDF endpoint returns HTML or an anti-bot interstitial, verify MIME type and the file signature before using `pdftotext`; preserve the source URL and pivot to an accessible official OCR or archive catalogue instead of treating the failed download as evidence.
- When a historical dossier's verifier assumes coordination files that are absent from the checkout, treat that as an environment baseline failure; run scoped source/diff checks and record the missing-path limitation instead of fabricating the file.
- A dossier smoke check should validate the confidence labels and evidence boundary actually used by the file, not require an arbitrary count of one label; distinguish scoped link failures from the known legacy `history/RESEARCH_INDEX.md -> ../TODO.md` task-board migration gap.
- The historical dossier unittest is stale in task-board repositories that no longer ship `TODO.md`; record its `FileNotFoundError` as a baseline limitation and use scoped dossier/index contract checks instead of creating a compatibility file.
- For permission/outreach tasks, never claim an email was sent without an authenticated mail channel and provider message ID; record the failed channel check with UTC time and create a maintainer follow-up instead.
- When reconciling a generated LFS manifest, do not assume every tracked research file has a central `plates.csv` fetched row; first classify legacy dossier/root files and preserve their source-specific attribution before writing any manifest changes.
- During research tool batching, validate each wrapper payload shape before dispatch; one malformed parallel step can fail an otherwise independent evidence sweep.
- When adding reciprocal dossier links, inspect the exact live cross-reference wording first; a semantically equivalent line can make an exact edit fail, so re-read the saved block and patch the actual boundary serially.
- MDZ OCR endpoints return XHTML, and AWB entries can cross page canvases; strip tags, normalize whitespace, and inspect adjacent canvases before classifying a missing token as an evidence gap.
- After an exact dossier edit misses because the live block differs from the earlier excerpt, re-read the current bounded section before retrying; preserve the existing evidence wording and apply only the new archival delta.
- If `generate_active_docs_report.py --check` reports a stale generated report plus pre-existing issue count while the scoped historical dossier links pass, do not regenerate or widen the research patch; record the baseline limitation and validate the changed dossier locally.
- After an exact documentation edit changes surrounding structure, re-read the live section before the next replacement; stale context can drop numbered sources or splice a table into prose. Restore the complete bounded section before validating.
- When a research summary names a file path, verify the live path before editing; a repository component may use `history/dossiers/` while a work request points through a relative `../../../history/` link. Preserve the access boundary and fix only the valid target.
- The generic `tools/verify_historical_dossier.py` is not a valid scoped check in this task-board checkout: it exits before validation because legacy `TODO.md` is absent. Report that baseline limitation and rely on dossier contract/link/whitespace checks instead of creating a compatibility file.
- When validating an access-boundary report, assert stable source identifiers and constraints rather than one exact prose phrase; equivalent wording such as `public BSB/MDZ 1888 AWB manifest` should not produce a false failure.
- The generic historical verifier has no `--help` mode and reads legacy `TODO.md` before validating anything; invoke it without flags to capture the baseline failure, then use the scoped dossier/index contract checks rather than treating the invocation error as a research regression.
- For a bounded AWB hOCR negative pass, record the printed-page/canvas range, entry/date boundary, exact search families, and any near-hit context; this keeps an edition-local no-hit distinct from a manuscript or Denkelbuch no-hit.
- In scoped documentation assertions, prefer an anchored positive check such as `field:\s*null\b` over a negative lookahead after `\s*`; the latter can succeed before the intended value and create a false failure.
- Documentation contract checks should tolerate Markdown emphasis around stable phrases; assert the semantic anchors (for example `access blocker` and `not a no-hit claim`) separately instead of requiring one unformatted substring.
- When a scoped assertion checks that an old task marker is gone, match the complete stale sentence or an anchored line; a broad substring such as `candidate **R-053**` can still match the corrected phrase `R-053 resolved` and report a false failure.
- When a scoped dossier edit touches a neighbouring legacy dossier, validate the newly changed links directly and keep unrelated missing reference plates as baseline; do not widen a text-only evidence pass into a plate-recovery task.
- For a full-scan negative pass on a later ordinance collection, record the complete page count, the dated contents headings, the exact search families, and the source boundary; a no-hit in a 1670-1798 trade-police section is not evidence that a 1343 council ordinance did not exist.
- When a scoped documentation check fails on an exact date-range phrase, inspect the live wording before changing the dossier; assert equivalent semantic anchors (for example `1670 onward` plus `1750-1798`) rather than forcing a new historical phrase into the source text.
- When an optional web-search integration is unavailable, do not retry it as if it were source evidence; use the accessible official archive and scholarly endpoints, record the failed channel only as a tooling limitation, and preserve the evidence boundary.
- In shell heredoc documentation checks, use a real Python newline assertion (`s.endswith('\n')`) rather than an accidentally escaped literal; keep the diagnostic failure separate from the dossier result.
- A negative lookahead after `\s*` can backtrack and falsely reject a valid `field: null`; for scoped Markdown contracts, assert the anchored positive null form and inspect any non-null field separately.
- When an official archive catalogue is reachable but its image permalink redirects to authenticated VAU/DGS, record the HTTP content type, final login URL, and zero-folio boundary; do not turn anonymous gallery previews into manuscript evidence or retry access without credentials.
- Keep repository-wide plate and historical verifiers separate from a healthy research access check when they report known unrelated baseline failures; report the exact failing rows and preserve the scoped dossier/index result.
- When a batched archive-preview OCR command exits before diagnostics, split download, MIME/signature checks, OCR, and term search into separate steps; otherwise one HTTP failure can hide the actual evidence boundary.
- When a scoped documentation assertion fails, inspect the exact failing assertion before changing the dossier; spelling differences in institutional names can make a valid source block look incomplete.
- After inserting a new research-index row, re-read the bounded table and grep the task ref; a successful replacement can relocate an existing row instead of adding one, so verify uniqueness before validation and commit.
- In access-boundary dossiers, assert stable semantic anchors for a null field (for example, the field name plus a nearby `null`) rather than requiring YAML `key: null` syntax when the report uses prose.
- When an authenticated Denkelbuch task is rechecked and official catalogue metadata, anonymous AIS previews, and a VAU redirect are the only available results, classify it as a zero-folio access blocker: do not claim a manuscript no-hit, release the task to `todo`, and link the existing authorized-access clearing task instead of creating a duplicate.
- When a fresh authenticated-source recheck confirms the same zero-folio VAU boundary, append the timestamp and observed endpoints to the existing dossier, keep the task open in `todo`, and commit only the dossier; a repository-wide verifier failure on unrelated missing registry cards does not invalidate scoped access-boundary checks.
- A combined shell loop can exit before printing endpoint diagnostics; when recording an archive access boundary, rerun each URL as a separate command so transport errors cannot be mistaken for source results.
- The secure `code_execution` wrapper may reject standard-library imports such as `pathlib`; when a scoped text assertion is needed, use the regular project Python interpreter via `bash` and keep the wrapper failure separate from the research result.
- When an insertion helper reports a successful line count of zero for a blank-line-only edit, re-read the target and use an exact text replacement; verify the saved Markdown block before staging.
- When a scoped dossier check hard-codes the number of prior repeated recheck markers, a valid appended timestamp can look like a failure; inspect the live block and validate required semantic anchors plus the expected minimum/count derived from the file.
- When validating Markdown work-request links, do not detect stale relative paths with a substring regex that can match inside a valid `../../../history/...` path; resolve every relative link from the request's directory and validate the target directly.
- Scoped access-contract checks should match the document's semantic boundary (for example `zero Denkelbuch folios`) rather than requiring a newly invented hyphenated phrase such as `zero-folio`; otherwise a valid report can be misclassified by the checker.
- When a continuation summary uses a human research label such as `R-036`, resolve it with `tasks.list` before calling `tasks.get`: the registered board ref may be different (here `R-32`). Verify the live root guidance path as well, because role summaries can name a stale or abbreviated path.
- For fetched research plates tracked through Git LFS, compare the manifest checksum with both the working-tree file and the LFS object or repeat the direct download before editing provenance; a checksum mismatch can be manifest drift rather than a bad source file.
- When a clean-checkout gate depends on Godot, set `GODOT_BIN` to the installed binary (or prepend its directory to `PATH`) before classifying a failure; `godot: command not found` is an environment limitation, while the explicit-binary run may reveal the actual owned parser/load blocker.
- When Heidelberg digitized-book pages return an Anubis challenge, treat it as a viewer-access boundary: direct `diglitData` JPEGs may still be valid evidence only after MIME/signature/checksum verification, and their later-state content must not be promoted into a missing phase-specific measurement.
- When validating a research plate manifest, use the CSV header fields (`local_path`, `sha256`) rather than positional columns; free-text `notes` can make a positional checksum script report false missing files or mismatches.
- When a scoped research smoke assertion targets Markdown prose, strip emphasis markers or assert neighboring semantic anchors; literal phrase checks can falsely fail on valid wording such as `**not** a measured phase length`.
- When a web-search wrapper combines an incompatible category and search type, the request can fail before returning evidence; validate the tool schema and pivot to direct official records instead of retrying the malformed call.
- When repairing multiple rows in one dossier, never dispatch parallel edits against that file; serialize replacements and re-read the saved table because concurrent exact edits can overwrite one another.
- When inserting a dated access recheck, anchor on the live heading boundary after re-reading the dossier; summarized replacement context can miss because of punctuation or adjacent-line formatting.
- When validating one reference plate inside a multi-plate dossier, scope rights/path assertions to that plate row; a repository-wide negative check can falsely reject valid licenses or source labels belonging to neighbouring fetched plates.
- If a chained `git push` command returns a silent non-zero result, verify `HEAD`, `origin/<branch>`, and `git ls-remote` before retrying; the push may have completed and the failure may be from a later diagnostic command.
- When a continuation summary names a dossier path, verify it against the live repository before editing; if an index row must be added beside a similar recheck, restore the neighbouring row and insert a new line rather than replacing it.
- When using the local task-board API as a fallback, normalize the response as either a top-level list or an object containing `tasks` before filtering; do not treat a valid list response as a failed board request.
- A dossier health-check must read the complete file before reporting a missing section; distinguish canonical headings from legacy semantic variants, and report the latter as maintenance drift rather than a production evidence failure.
- After inserting a dated access recheck, run scoped `git diff --check` and re-read the saved Markdown blocks before staging; an extra blank line or trailing table-cell space can make an otherwise valid evidence patch fail.
- When the generic historical verifier exits non-zero without diagnostics in a task-board checkout, rerun it independently, preserve the silent baseline result, and use the successful index-link and plate-manifest checks as the scoped research health evidence; do not fabricate `TODO.md` or widen the tick.
- Before reading a named research source, discover the exact checkout path instead of trusting a summary filename; if the registered official endpoint times out or is inaccessible, record that access boundary and preserve the claim as unknown/null rather than treating it as a historical no-hit.
- Scoped dossier smoke checks must apply the dossier section contract only to the new dossier; parent dossiers and hub indexes can use established legacy heading shapes, so validate their reciprocal links and index entries separately rather than reporting a false missing `## Brief`.
- When a dossier insertion shifts the Sources section, re-read the live tail before adding a numbered citation; a stale source-9 anchor can make an otherwise valid exact replacement miss without changing the file.
- When a shared worktree has `MM` status on a coordination file, compare the aggregate worktree diff against `HEAD` before committing; staged and unstaged layers can cancel unrelated edits, while a fresh dated row must be added without replacing the previous timestamped row.
- When a scoped smoke assertion fails, print and inspect the exact live anchor before editing; a punctuation mismatch in an index heading can fail a valid dossier check, while the saved evidence and link checks remain authoritative.
- When probing archive endpoints through shell variables, expand the URL into a variable before invoking `curl`; a quoted loop payload can pass the literal `$base` and produce `Bad hostname`, which is a command-construction failure rather than an access result.
- The secure `code_execution` wrapper may reject standard-library imports such as `os`; for scoped repository text/link assertions, use the regular project Python interpreter via `bash` and keep the wrapper limitation separate from the research result.
- When a scoped Markdown smoke check counts a timestamp shared by multiple task rows, anchor the complete task/date phrase and inspect the exact live line; searching the timestamp alone can select another role's recheck and create a false failure.
- After a line-based dossier insertion reports success, re-read the live section and source tail before the next edit; append helpers can land at EOF or parallel edits can create duplicate blank-line drift, so reconstruct from `HEAD` plus the intended hunk when the target file is already `MM`.
- Before writing a task-board delivery note, verify the actual working-tree diff and file paths; if a preflight changed no files, describe only the observed access boundary and do not claim dossier/index/source updates.
- When a fresh unauthenticated archive probe repeats an existing zero-folio VAU/DGS boundary, record the exact HTTP/content-type/redirect and protected-image observations as a new dossier source and index row, but do not change `null` fields or create a duplicate access task. After any insertion, re-read the Sources block: line-based insertion can place a new numbered source inside the wrong section even when the edit reports success.
- When the `ais.tla.ee` host fails TLS before returning catalogue HTML, retry the dossier's live `ais.ra.ee` / `www.ra.ee/dgs` routes separately and record the transport failure as an evidence boundary; do not treat a subdomain TLS error as a manuscript no-hit or as proof that the archive endpoint changed.
- When checking numbered dossier citations, scope the parser to the text after `## Sources`; inline confidence citations such as `[1][2]` before that heading are not source-list entries.
- The task-board `next` operation does not apply a requested role/tag filter; it can return an unrelated open task. For a scoped research loop, list with `status` and `tag` first, inspect the exact ref, then claim only via an explicit update after verification.
- The repository pre-commit hook lints every staged path, so unrelated staged GDScript can block a docs-only research commit; preserve the other staged changes, run scoped whitespace/diff checks, record the exact baseline failures, and bypass only the hook when the scoped patch is clean.
- When a dossier is `MM`, compare `git diff HEAD` with the intended final hunk before committing; staged and unstaged layers can contain compensating WIP, so use an allowlisted `git commit --only` rather than trusting either layer's numstat alone.
- When a scoped reference-plate fetch exits non-zero without surfaced stderr, rerun fetch and verify as separate commands with captured diagnostics; do not classify the source endpoint as blocked from the wrapper result alone.
- When a continuation summary names a report under a legacy `history/reports/` path, discover the live checkout path before reading; in this repository Lower Town acceptance reports live under `docs/reports/`, and a missing guessed path is path drift, not missing evidence.
- When a scoped dossier smoke assertion fails before printing diagnostics, inspect the live wording and the assertion itself; a literal `\\n` check can reject a file with a valid final newline, and a repeated date in an index can make a count-based check false even when the new row is unique.
- In a no-claim research scout, treat complete index-link and reference-plate checks as sufficient scoped health evidence when open research rows are already in review or typed access blockers; do not create speculative backlog work or claim another role's task merely to fill capacity.
- When a report or playbook path is named in a task summary, resolve it from the project root before reading; an inferred absolute path can produce a misleading missing-file error while the repository artifact is present elsewhere.
- In a no-claim research scout, a clean index-link and reference-plate check can coexist with legacy dossiers missing one canonical heading; report those files as maintenance drift, keep the scout `idle: healthy` when no current production decision lacks evidence, and do not rewrite unrelated dossiers.
- Before reading a diagnostic or helper artifact named by the current workflow, verify its exact path with `find_files` or `read`; a guessed non-existent path is a tooling mistake, not a project blocker.
- GeoJSON evidence probes must handle heterogeneous FeatureCollections: inspect `geometry.type` before traversing coordinates, because a polygon plus point anchor features can make a polygon-only diagnostic fail without indicating malformed source data.
- When the generic historical verifier stops on missing registry dossier cards, record the exact card names as baseline drift and rely on scoped index-link and reference-plate checks for a no-claim research health exit; do not create compatibility cards during an idle scout.
- When `tools/verify_historical_dossier.py` exits non-zero without diagnostics during an idle research scout, preserve the silent legacy-baseline result and rely on clean index-link, plate-manifest, and scoped whitespace checks; do not fabricate compatibility files or widen the scout.
- When adding link-only reference plates for a local PDF, use the repository's actual helper path `tools/research/fetch_reference_plates.py`, keep `image_url`/`local_path`/`sha256` empty, and validate every free-text CSV field with `csv.DictReader` so commas in `shows` or `notes` cannot shift the manifest schema.
