# HUD, menus, journal, and maps

Status: implemented. Scope: every player-visible screen outside dialogue and forge commissions: main menu, quick-access bar, HUD elements, journal, Hingepuu reflection, world map and fast travel, interaction prompts, cursor. Controller/presentation ownership rules are in [`ARCHITECTURE.md`](../ARCHITECTURE.md#ui-and-interaction-ownership); bindings are in [`CONTROLS.md`](../CONTROLS.md).

## Main menu

`scenes/menu/main_menu.tscn` (the project's main scene, with an intro video):

| Entry | Script | Behavior |
|---|---|---|
| Start | main menu scene | New game into Lower Town |
| Load | `scenes/menu/load_label.gd`, `save_list_overlay.gd` | Hidden when no save exists; lists slots with phase, location, and time ([`STATE_AND_SAVES.md`](./STATE_AND_SAVES.md#saves)) |
| Credits | `credits_label.gd`, `credits_screen.gd` | Renders `CREDITS.md`, generated by `tools/generate_credits.py` from the audio manifests ([`music/README.md`](../../music/README.md)) |
| Assets library | `assets_library_label.gd`, `assets_library.gd` | Browse every imported GLB under `res://assets`, orbit it, play its clips (`AssetLibraryCatalog`). Authoring aid |
| Exit | `exit_label.gd` | Quit |

## In-game quick-access bar

`QuickAccessMenu` (`scripts/ui/quick_access_menu.gd`) is the persistent action bar at the bottom of the screen. Every player-visible action has a button here, plus a hotkey where one exists:

**Inventory [I]**, **Journal [J]**, **Reflect** (Hingepuu), **Map [M]**, **Camera [C]** (third-person → first-person → top-down), **Controls [K]**, **Iron** (forge technique toggle), **Magic [R]** (spell cookbook), **Save game**, **Debug**.

Esc opens Settings ([`SETTINGS_AND_ACCESSIBILITY.md`](./SETTINGS_AND_ACCESSIBILITY.md)).

## Journal

`JournalController` / `JournalModel` / `JournalOverlay` (`scripts/journal/`). Tabs show active quest objectives and discovered facts (never spoiling outcomes), commission deadlines, and the faction ledger ([`FACTIONS_AND_ECONOMY.md`](./FACTIONS_AND_ECONOMY.md)).

## Hingepuu reflection

`ReflectionController` / `ReflectionModel` / `ReflectionOverlay` (`scripts/reflection/`). The reflection-morning recap of convictions and marks, opened from **Reflect**. Design: [`PSYCHE.md`](./PSYCHE.md), [`NATURAL.md`](./NATURAL.md).

## World map and travel

`WorldMapController` (on every playable player host) opens `WorldMapOverlay`, which has three views:

- **Local**: the full-screen version of the minimap (`WorldMapLocalView`).
- **Fast travel**: the Reval district graph built from the active transition manifest (`WorldMapGraph`, `WorldMapFastTravelView`). Click or focus a district to travel through `DoorNavigator`.
- **Global**: an Estonia basemap with distant locations from `GlobalMapCatalog`, kept off the district graph (developer-traversable placeholders).

Doors and transitions: `DoorNavigator` autoload and `content/transitions/active_destinations.json` ([`MAP_AUTHORING.md`](../MAP_AUTHORING.md)).

## Interaction

`InteractionController` picks the focused `Interactable` within radius. Interactables carry a kind from `InteractionKinds`. World items use the same contract ([`WORLD_LIFE.md`](./WORLD_LIFE.md#world-items)). Primary-click meaning per camera mode is in `PlayerPrimaryAction` and [`CONTROLS.md`](../CONTROLS.md).
