# Architecture Typology across the journey nodes
**Status:** planned (design proposal, not implemented) · **Scope:** cross-cutting catalogue of building types and their shared-kit ids (`asset.kit.*`) for the `loc.world_*` nodes; defines the ids that location pages cite; no runtime change · **Confidence:** typology `plausible composite` from regional medieval practice; named buildings `attested` only where stated; 1343 construction states are flagged where unverified.

Rules carried from [AGENTS.md](../../AGENTS.md): realistic 3D/procedural assets only (ADR 0022); no legacy pixel/isometric art; map authoring goes through `MapBlueprint` primitives and reviewed prefabs, not new giant dictionary factories ([MAP_AUTHORING.md](../MAP_AUTHORING.md)). Known anachronisms are listed in [TOURIST_LANDMARKS.md](../TOURIST_LANDMARKS.md). Stable IDs below are proposals; once a prefab ships, its ids never change.

## Shared elements
- Stone: Reval limestone (grey-yellow), Saaremaa dolomite (paler), Tartu brick (red), Padise stone (grey).
- Decorative language per node should differ: Hanseatic gable stepping (Reval), plain austere Order walls (Paide), pale dolomite (Pöide), brick tracery (Tartu), log walls (rural).
- Construction state: show scaffolds on Tartu cathedral and stone phase buildings; avoid showing completed buildings that were finished later.
- Prefab ids: place via `MapBlueprint` prefab packages. Never rename once shipped.
