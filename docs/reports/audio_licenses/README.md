# Audio license records

Per ADR 0035, the person approving an audio source stores a copy of the primary license text here, one folder per source (for example `sonniss_gdc_2026/`, `stable_audio_3/`). Secondary summaries are not approval. Keep files small (text or PDF); no audio belongs here.
