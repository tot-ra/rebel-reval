# Citizen cards

One Markdown file per person, in the district folder of their home: `lower_town`, `toompea`, `toompea_foot`, `kalarand` (fishing beach), `viru_road`, `harju_road`, `karja_road`. Structure: [`../TEMPLATE.md`](../TEMPLATE.md). Rules for writers: [`../WRITING_CARDS.md`](../WRITING_CARDS.md). Selection and method: [`../CENSUS.md`](../CENSUS.md).

Cards come in whole households wherever possible, so family members, masters and servants link to each other, and neighbours, trade partners, creditors, confessors and cell members are linked through a planned network whose every relationship has one agreed fact written from both sides. Each card carries the census seed (height, build, hair, eyes, marks, voice) as a fixed point for 3D body specs and portraits.
